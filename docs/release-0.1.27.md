# OxyMac Cleaner 0.1.27 Preview

«Выбрать по поиску» отмечает все доступные выключенные устройства из результатов поиска, включая следующие страницы. Прежний выбор устройств заменяется, чтобы скрытые старые отметки не попадали в новую выборку. Выбор runtimes остаётся отдельным; рядом показаны оба счётчика.

Выбор устройств без установленной ОС перенесён в «Ещё» и тоже учитывает поиск. Выбор ничего не удаляет; проверки перед удалением сохранены.

Apple Silicon, macOS 14+, ad-hoc подпись.
