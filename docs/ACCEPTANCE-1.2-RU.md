# OxyMac Cleaner 1.2 — кандидат, build 58

13 октября 2026. Продолжение плана после 1.1, не подтверждение завершённой UI-приёмки.

## Изменения

1. Незавершённая UI-проверка 1.1 (агенты, объяснения, следующая страница файлов) остаётся открытой: при повторной попытке служба управления интерфейсом вернула `Sky Computer Use native pipe closed before response`. Доступ к UI не восстановлен. Рабочая установленная 1.1 не заменяется автоматически этой сборкой.
2. Ограниченный LRU-кэш готовых запросов файлов: до четырёх результатов, суммарно до 1600 строк. Отдельный кэш карты — до четырёх папок, суммарно до 8000 узлов. Большие результаты не кэшируются. Изменение снимка или исключений создаёт новый файловый индекс. Фильтры по возрасту не кэшируются: результат зависит от текущего времени. Отмена проверяется и при попадании в кэш. Кэш не является разрешением на удаление; перед действиями остаются свежие проверки. Сокращены преобразования путей при построении карты.
3. Каталог метаданных приложений из `/Applications` и пользовательской папки Applications (корень и одна вложенная группирующая папка). Сверка точного ID контейнера с Info.plist только при единственном совпадении; групповые контейнеры не приписываются одному приложению. Для явно выбранного проекта показывается найденный маркер. Владелец по метаданным отличается от предположения по пути, основание доступно в подсказке. Неизвестный владелец остаётся неизвестным; отсутствие приложения не означает разрешение удалить его данные. Каталог читается в фоне, содержимое пользовательских документов не анализируется.
4. Узкие Python-кэши поддерживают также `pytest.ini`, `ruff.toml`, `.ruff.toml`. Это расширение вариантов конфигурации уже поддержанных инструментов, не универсальная очистка кэшей. Нужны точная подпись CACHEDIR.TAG, корень Git, ignored/untracked, отсутствие активности, давность записей, неизменность метаданных и манифеста. SQLite, исходники и секреты остаются защищёнными. У pytest теряется список прошлых ошибок, Ruff пересоздаёт кэш при следующем запуске. Проверки конфигурации не являются полным TOML/INI-парсером.
5. Сводка сохранности формулировок по категориям в результате оптимизации. Для текущего редактируемого текста отдельно считаются ссылки и присутствие дословной формулировки проверяемого черновика. Пересчёт в фоне с отменой, после редактирования. Это не оценка смысла всей истории и не доказательство актуальности; сравнение с исходником остаётся отдельным действием. Заголовок результата теперь «Результат для проверки».

## Проверки

Полный прогон: 245 тестов, 0 ошибок, 60,05 секунды. После профилирования заменён дорогостоящий поиск подстроки в нормализованных путях на буквальный NSString-поиск; проверены регистр, диакритика, русский и японский текст. Результаты замера снимка будут добавлены после завершения. Новые сценарии проверяют ограничения LRU, отмену при попадании в кэш, зависимость возрастного фильтра от времени, изменение исключений, границы папок, неоднозначные ID приложений, раздельный подсчёт ссылок/формулировок, изменение конфигурации кэша после предпросмотра. Удаляются только собственные фикстуры тестов.

## Источники правил

- [Ruff — конфигурация](https://docs.astral.sh/ruff/configuration/): поддерживаемые имена конфигурационных файлов.
- [pytest — кэш](https://doc.pytest.org/en/stable/how-to/cache.html): назначение кэша и потеря сохранённого состояния тестов при его очистке.

## Ограничения выпуска

Живая UI-приёмка новой сборки, новое обновление установленного приложения и повторная проверка TCC пока не выполнены. Developer ID остаётся отложенным. Полная загрузка большого снимка всё ещё хранит метаданные в памяти; этот этап ускоряет повторные запросы, а не устраняет основную стоимость хранения многомиллионного снимка. Автоматическая очистка не добавлена.
