# OxyMac Cleaner 0.4.10 Preview

В меню «Действия с архивом» доступны удаление отдельного архива и перенос в карантин, в том числе для последнего архива приложения. Лимит хранения по-прежнему действует на массовую очистку. Явная защита «Не удалять», исключения, неполные метаданные, активные сборки, свежие изменения и проверки целостности не обходятся.

Перед действием показываются последствия. Для удаления можно включить резервную копию; карантин позволяет восстановить архив, но пока занимает место. После операции список обновляется. Открытый Xcode сам по себе не блокирует действие; активный xcodebuild блокирует.

182 теста пройдены, включая перенос последнего архива в карантин, восстановление и удаление на собственном тестовом наборе. Пользовательские архивы при разработке не удалялись.
