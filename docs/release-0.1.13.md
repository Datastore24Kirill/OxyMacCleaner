# OxyMac Cleaner 0.1.13 Preview

В архивах Xcode добавлено «Удалить сверх лимита…». Карантин теперь альтернатива, а не обязательный промежуточный этап для массовой очистки архивов.

Оба действия создают или проверяют полные резервные копии. Прямое удаление отдельно подтверждает число и логический объём прошедших проверки архивов; оригиналы удаляются без карантина и Корзины. Сохранённые копии не удаляются. Восстановление — вручную из копии.

Перед каждым удалением перечитываются лимиты хранения, проверяются защита архива, исключения, состав исходника и копии и отсутствие активного Xcode/сборок. Ошибки пропускаются с отчётом. Отмена действует между архивами. При частичной ошибке удаления сообщение указывает путь копии, инвентаризация обновляется.

Пояснения и справка обновлены. Проверена необходимость карантина в остальных разделах: симуляторы уже удаляются напрямую; обычные файлы и дубликаты сохраняют карантин, DerivedData отмечен как следующий кандидат на отдельный режим прямого удаления. Подробности: docs/QUARANTINE-POLICY-RU.md.

macOS 14+, Apple Silicon. Подпись ad-hoc: разрешения macOS после обновления могут потребовать повторного предоставления. Пользовательские данные при проверке этой сборки не удалялись.
