# Приёмка 0.4.14 — пять направлений ТЗ

## 1. Качество контекста

Исправлено ограничение просмотра первыми 200 важными фрагментами: доступна следующая страница и возврат к началу. Число совпадений, номера на странице и укороченные записи показаны явно. Регрессия: 610 сигналов, позднее изменение на позиции 450, уникальные смещения, открытие соответствующего исходника, отмена.

Локальная Qwen 2.5 7B прошла многочастный сценарий с изменением лимита, запретом удаления оригинала, противоречащими результатами тестов, неопубликованным релизом и скрытием синтетического секрета. Реальная история Cursor/YooGo: 59 сообщений, 5 служебных записей; оригинал и копия совпадают, 20 из 20 контрольных фрагментов найдены в результате. Это проверка целостности и буквальных фрагментов, не независимая смысловая оценка.

Сопоставление связанных решений ограничено текущей страницей и общими словами. Оно не определяет актуальное решение. Длинные записи проверяются по префиксу; полный источник доступен отдельно. Автоматического изменения баз агентов нет.

## 2. Интеграции

Добавлена [матрица доказательств](AGENT-EVIDENCE-RU.md): девять нативных форматов и два текстовых экспорта. Для каждой строки указаны реальные тесты и ограничения. Версии производителей не выдумываются; неизвестный формат остаётся отказом.

## 3. Очистка и восстановление

193 локальных теста прошли, включая сверку снимка после очистки, защиту данных, конфликты восстановления и учёт жёстких ссылок. Отдельно пройден перенос собственного тестового каталога на реальный USB Samsung T5 (HFS+) и восстановление: байты файла, пустая подпапка, отсутствие старого внешнего payload. Собственные фикстуры удалены; пользовательские файлы не изменялись.

Установщик проверен на собственных фикстурах: успешный запуск и откат при отсутствии подтверждения. Физическое отключение пользовательского диска намеренно не выполнялось. Точный выигрыш APFS-блоков не обещается.

## 4. Интерфейс

Новая навигация важных фрагментов локализована RU/EN, имеет доступные имена и отключается во время операции. Локальная UI-проверка установленной сборки фиксируется ниже. Предыдущая пользовательская проверка VoiceOver сохраняет силу для проверенного тогда состояния; она не заменяет полный независимый аудит новой версии.

## 5. Совместимость

В CI добавлена отдельная сборка и тесты на macOS 14. Среда и архитектура выводятся в журнал. Основная упаковка остаётся macOS 26. Hosted runner macOS 14 выводится из эксплуатации 2 ноября 2026; потребуется отдельный хост, а не молчаливая замена на latest.

Чистая установка на втором физическом Apple Silicon Mac и дополнительные версии Xcode/runtime остаются внешними проверками. [Сценарий приёмки на другом Mac](SECOND-MAC-ACCEPTANCE-RU.md). Developer ID отложен, непрерывность разрешений ad-hoc сборок не гарантируется.


## Дополнительные находки

Первый прогон CRM остановлен валидатором ссылок: модель выдала отсутствующие номера. Исходник и резервная копия сохранены. Добавлен ровно один повтор выбора ссылок для проблемной части; повторный неверный ответ остаётся ошибкой. Сетевые ошибки не повторяются этим механизмом. Автотест проверяет успешное исправление и отказ после двух неверных ответов.

Первый CI macOS 14 выявил несовместимые со старым компилятором захваты изменяемых переменных и чрезмерно сложные SwiftUI-выражения. Захваты сделаны явными, блоки архива и строка оценки объёма разделены без изменения правил очистки.

UI smoke: по 12 разделов для RU/EN × светлая/тёмная, заголовки и выбранное состояние доступны в accessibility tree. Настройки визуально проверены в светлой и тёмной теме при 1180×800. Это не утверждение полного визуального аудита каждого диалога и всех размеров.


## Финальные результаты

- CRM, локальная 7B: 87 частей, 449 сообщений + 12 служебных записей. После ограниченного повтора прогон завершился, 128 из 128 контрольных фрагментов присутствуют. Исходник и копия совпадают. Выборочно сверено позднее уточнение пользователя: оно сохранено, прежние утверждения не объявлены автоматически актуальными.
- Размер CRM: 881 133 байта исходника → 739 404 байта результата. Сокращение всего около 16%; задача компактного смыслового переноса **не закрыта** этим прогоном. Проверяемые цитаты безопаснее свободного пересказа, но требуют ручного отбора. Независимая оценка смысла остаётся открытой.
- UI на собственной истории: 205 сигналов, переход 1–200 → 201–205, конец списка отключает дальнейший переход, Escape закрывает окно. Проверена тёмная компоновка окна сравнения.
- GitHub CI на коммите b99aaae: macOS 14 и macOS 26 успешны, 193 теста; основной job также проверил установку/откат и упаковку. Это CI, не чистая установка на другом физическом Mac.
- Финальная локальная 0.4.14 установлена; предыдущая копия сохранена. Снимок 237 450 файлов / 67,29 GB сохранён. После штатного повторного добавления текущей копии в FDA и перезапуска проверенные защищённые папки доступны. Само обновление ad-hoc подписи всё ещё не сохраняет доступ автоматически.

Приватные результаты тестов остаются только локально; содержание историй и их резервные копии в GitHub не отправлялись.
