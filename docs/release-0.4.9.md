# OxyMac Cleaner 0.4.9 Preview

Исправлен импорт реальных историй Cursor, содержащих служебные записи turn_ended. Они сохраняются целиком и не превращаются в сообщения или свидетельство успешных тестов. Добавлена регрессия для некорректных служебных записей.

После смены языка в простое строка статуса обновляется на выбранном языке. Исторические журналы и пользовательское содержимое не переводятся.

Проведена локальная проверка одной реальной истории Cursor на 7B: все пять пользовательских сообщений и итоговый незавершённый статус сохранились, исходник не изменён. Это не гарантия смысловой полноты любых историй. Содержимое истории не публикуется.

180 тестов ядра прошли. Статус Preview; Developer ID и проверка пользовательской очистки остаются открыты.
