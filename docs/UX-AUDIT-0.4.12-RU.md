# UX-проверка 0.4.12 — 8 октября 2026

## Цель и изменения

Сценарий: выбрать задачу → просмотреть результаты → отметить ненужное → проверить последствия → подтвердить действие. Вдохновение: [Smart Care](https://macpaw.com/support/cleanmymac/knowledgebase/smart-care); защитные ограничения OxyMac сохраняются.

- Обзор: четыре визуальные карточки основных задач; завершённый прогресс не занимает экран.
- Боковое меню сгруппировано по задачам. Изображение бренда не загружается с диска на каждую перерисовку.
- Файлы: индекс и фильтрация в фоне, кэш на снимок и исключения, отмена устаревшего поиска, первые 200 строк с дозагрузкой. Защищённые объекты скрыты по умолчанию. Фильтр позволяет только просмотр; защита очистки независима от индекса.
- Карта: справочник файлов строится в фоне; список ограничен 200 строками с дозагрузкой.
- Архивы Xcode: правила хранения и резервной копии в раскрывающемся блоке; поиск, выбор и два действия остаются на виду.
- Кэши Xcode: «Индекс кода», «Промежуточные сборки», «Журналы сборок» и последствия очистки. Техническое имя — в подробностях.
- Локальный движок: автоматические проверки состояния не чаще 30 секунд; ручное обновление остаётся немедленным.
- Пустой список симуляторов считается загруженным и не перечитывается при каждом переходе.

## Автоматическая проверка и производительность

187 тестов прошли без ошибок. Новые тесты: защищённые пути, исключения, жёсткие ссылки, карантин, Archive+Downloads, поиск/возраст/размер, пагинация, отмена, соответствие кэшированной классификации исходным правилам.

На одинаковом синтетическом наборе 100000 файлов в Debug: построение индекса 15,606 → 0,457 секунды; два запроса к готовому индексу — 0,167 секунды. Это измерения ядра, не гарантия времени каждого перехода UI. При первом входе на реальном большом снимке остаётся фоновая подготовка с индикатором.

Release-пакет собран; codesign --verify --deep --strict пройден. Визуально проверены тёмная системная тема, файлы и архивы, а также Обзор в светлой теме. Исходная системная тема восстановлена. Полный визуальный проход всех экранов в светлой теме и VoiceOver в этом проходе не выполнен.

## Незакрытый дефект macOS: previous.app

У текущей сборки правильные CFBundleName/DisplayName, иконка и канонический путь. Старый установщик переименовывал резервную копию в previous.app; новый сохраняет имя OxyMac Cleaner.app. Физических старых previous.app рядом с установленной копией нет.

Запись удалена штатно в System Settings и добавлена заново из /Users/oxyfire/Applications/OxyMac Cleaner.app; Launch Services обновлён, Settings перезапущены. Доступ работает, однако macOS всё ещё показывает previous.app и старый значок. Дефект отображения не закрыт. База TCC не редактировалась; гарантировать сохранность разрешений без стабильной Developer ID подписи нельзя.
