# OxyMac Cleaner 0.9.1 — 1.0 RC2

В «Возможностях очистки» появился общий план просмотра: конкретные объекты из проверенных источников, причины, владелец, риск, условия и восстановление. Источники без проверки доступны в раскрывающемся блоке.

- Три группы: восстанавливаемые данные разработки, ценные данные для просмотра, защищённые и непроверенные объекты.
- Порядок учитывает риск, полноту метаданных, размер и стоимость восстановления.
- Совместный предпросмотр исключает повторные пути, вложенные объекты и известные одинаковые inode, сохраняет резервную копию в группе дубликатов.
- Неизвестные размеры и неточность сумм каталогов обозначены явно. Это не обещание освобождаемого места.
- Версионированные правила и размеченные тестовые примеры. Действия выполняются в профильных разделах после повторной проверки.

macOS 14+, Apple Silicon. Предварительный релиз, без Developer ID: после замены приложения macOS может потребовать повторно подтвердить уже выданный доступ. Данные пользователя автоматически не удаляются.
