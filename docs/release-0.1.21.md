# OxyMac Cleaner 0.1.21 Preview

Потоковый импорт JSONL-историй Codex и Claude Code от 30 MB до 1 GB: приватный снимок на диске, построчная проверка, прогресс и отмена. Большие файлы больше не загружаются целиком в память. Модель получает снимок порциями до 12 000 символов; оригинальная история остаётся неизменной.

Требуется место для двух временных копий примерно размером с исходник и отдельной резервной копии перед генерацией. Временные файлы удаляются при освобождении импорта (например, смене агента); после завершения процесса могут остаться. Резервные копии сохраняются.

Ограничения: отдельная JSONL-строка до 8 MiB, итоговые заметки до 8 MB. При превышении — явная ошибка, без молчаливого обрезания. Универсальный текстовый импорт остаётся ограничен 30 MB. Качество пересказа на реальной локальной модели пока не проверено.

Apple Silicon, macOS 14+. Подпись ad-hoc; разрешения после обновления могут потребовать повторной выдачи.

121 core-тест прошёл. Импорт файла 30,1 MB проверен в установленном приложении.
