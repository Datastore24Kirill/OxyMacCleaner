# OxyMac Cleaner 0.1.19 Preview

Первый этап чтения историй Codex и Claude Code: выбор одной JSONL-сессии, проверка структуры и ID, счётчики сообщений и сохранённых событий. Неизвестные данные сохраняются, оригиналы не изменяются. Импорт вынесен из основного потока интерфейса.

Подготовка контекста работает через настроенную локальную модель и создаёт отдельный текст для нового чата. Это не уменьшает исходную историю на диске. Для остальных агентов остаётся универсальный импорт экспорта.

112 core-тестов. Готовая сборка для Apple Silicon / macOS 14+. Подпись пока ad-hoc; разрешения macOS между обновлениями могут потребовать повторной выдачи. Developer ID и автоматическое обновление остаются в плане.
