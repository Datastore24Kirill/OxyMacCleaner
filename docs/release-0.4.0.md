# 0.4.0 Preview — проекты, контекст и проверка копий

- Поиск проектов в выбранной папке: Swift, Xcode, Node, Rust, Python, CocoaPods и Git. Исключения, симлинки, облачные объекты и каталоги зависимостей не обходятся; лимит 50 000 объектов и отмена явно дают неполный результат. Из найденного проекта можно перейти к существующей проверке данных и рабочих деревьев. Код проектов не запускается.
- Просмотр всей импортированной истории страницами по 64 КБ, поиск точного текста или ссылки `[L123]`, отмена поиска. Потоковая история не загружается целиком в память. На текущей странице показаны маркеры изменённых требований и результатов тестов; это подсказки для ручной проверки, а не автоматическое разрешение противоречий.
- Добавлен узкий адаптер Aider: один сеанс `.aider.chat.history.md` с заголовком начала чата, до 30 МБ. Все строки сохраняются; объединённые сеансы отклоняются, роли по Markdown не угадываются. Исходный чат не переписывается.
- Проверка копий в карантине: доступность диска, целостность полезной нагрузки, результат восстановления и путь старой копии после переноса. Если восстановление завершено, но копия осталась, её можно отправить в Корзину только после повторной проверки обеих копий. Старые копии переноса показываются для ручного осмотра.
- Выбранные файлы показывают логический размер и занятые блоки отдельно, с устранением повторного учёта одного inode. Точная экономия APFS неизвестна из-за общих блоков, снимков и жёстких ссылок. Перенос в карантин на том же диске место не освобождает.
- Новые элементы получили RU/EN тексты, доступные названия, состояния ожидания и отмену. Полный аудит VoiceOver остаётся отдельной задачей.

152 теста прошли: обнаружение проектов, лимиты и исключения, полная история и Unicode, жёсткие ссылки, повреждённое назначение восстановления, Aider. Пользовательские данные не очищались. Сборка по-прежнему ad-hoc: сохранение разрешений macOS после обновления не гарантируется.
