# OxyMac Cleaner 0.1.0 — Preview

First native Apple Silicon implementation. macOS 14+. Download the ZIP, extract and move the app to Applications; no development tools needed.

- Selected-folder scanning, large files/folders, archive filtering and exact duplicate comparison.
- Individual-file quarantine, verified restoration and separately confirmed permanent deletion.
- Russian/English, light/dark/system appearance; optional five-day quarantine reminders.
- Read-only Xcode/simulator inspection and discovery catalog for 11 agents.
- Manual session-export import, verified backup and local Ollama context handoff with copy/Markdown export.
- Ollama download/install assistant and local-model downloads.

This preview is not the complete v1 specification. Native agent-history adapters, directory cleanup, automatic updates/rollback and real-model quality certification remain open. See docs/STATUS.md.

Ad-hoc signed, not notarized. SHA256SUMS.txt verifies the download. Test cleanup on disposable files first; quarantine still occupies disk space.
