# OxyMac Cleaner 0.1.8 Preview

- Раздел «Возможности очистки»: первые локальные правила, работающие по сохранённому снимку.
- Установочные файлы DMG/PKG/XIP/IPA в «Загрузках», не изменявшиеся 90 дней; личные файлы от 500 MB, не изменявшиеся 180 дней.
- Причина, дата изменения, размер, фильтр правил и поиск; проверка актуальности перед показом в Finder и исключение файла из предложений.
- Размер кандидатов не обозначается как гарантированно освобождаемое место. Автоматического выбора и удаления нет.
- Карантин папок и восстановление журнала из 0.1.7 включены.
- Боковая навигация прокручивается при недостатке высоты окна.

45 автоматических тестов прошли локально. Проверено восстановление пользовательского частичного снимка из 237450 файлов после обновления; снимок и прежнее приложение сохранены в резервной копии. Пользовательские файлы не перемещались и не удалялись.

Рекомендации Xcode, зависимостей и агентов ещё не включены: для них нужны отдельные проверки активности и восстановления. Дата изменения не является датой последнего использования. Результат зависит от полноты исходного обхода. macOS 14+, Apple Silicon; ad-hoc подпись.
