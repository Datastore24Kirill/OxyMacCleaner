## Изменения кандидата

Реализуются следующие изменения исходников:

- замена затратного разбора путей Foundation быстрым лексическим разбором;
- общий быстрый путь политики защиты для канонических путей снимка с возвратом к обычной проверке для необычных путей;
- кэширование специальных проверок Docker и резервных копий;
- отображение загрузки без ложных нулей, подписи прогресса, адаптивная сводка и число показанных строк.

Эти изменения не являются доказательством ускорения или живой проверки интерфейса. Защита файлов должна сохранять прежний контракт; ускорение не разрешает удаление по устаревшим метаданным.
