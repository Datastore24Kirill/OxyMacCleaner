# OxyMac Cleaner 0.1.2 Preview

- Иконка переведена в Icon Composer: убрана белая рамка при отображении в современной macOS.
- Анимированная панель сканирования с реальными счётчиками файлов и папок, объёмом, текущим путём, временем и скоростью.
- Цветная полоса показывает состав обнаруженного объёма. Процент завершения не выдумывается: при обходе диска полный список файлов ещё неизвестен.
- Остановка сохраняет частичный результат; завершённые и остановленные обходы показаны раздельно.
- Поддерживается системная настройка уменьшения движения.

Apple Silicon, macOS 14+. Скачайте ZIP и перенесите приложение в «Программы». Developer ID пока отсутствует. Это предварительная версия; существующие ограничения очистки и интеграций описаны в README.

Проверка: 21 автоматический тест, ручная проверка счётчиков, остановки и иконки в Finder.
