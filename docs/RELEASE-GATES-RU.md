# Критерии выпуска 1.0

Это конечный список приёмки, а не предложение бесконечно расширять функции. Preview остаётся до принятия открытых ограничений.

| Критерий | Состояние | Условие закрытия |
|---|---|---|
| Установка и обновление | Проверены локальная упаковка, целостность, запуск, откат на фикстурах; 0.4.8 опубликован | Проверка чистой установки на другом Apple Silicon Mac; Developer ID отдельно отложен |
| Реальная история агента | Один Cursor/YooGo пример проверен локально; найден и исправлен turn_ended | Для заявленных адаптеров фиксировать проверенные версии/форматы; неизвестное не переписывать |
| Очистка на реальных данных | Ожидает конкретного выбора пользователя | Один ненужный архив/кэш: выбор → подтверждение → отсутствие на диске → обновлённый список/размеры |
| Карантин | Перенос, конфликт восстановления, альтернативный путь, отмена и сбои проверены на собственных данных | Пользовательский файл по выбору: перенос → восстановление → сверка содержимого; без очистки карантина автоматически |
| Интерфейс | Основная навигация RU/EN, темы, подсказки и часть пустых состояний проверены | Полный список экранов/диалогов с клавиатурой и VoiceOver; исправление воспроизводимых дефектов |
| Совместимость | Apple Silicon, macOS 27, Xcode 27/iOS 27 инвентаризация; другие runtime — фикстуры | Отдельная проверка минимально заявленной macOS 14 и реального внешнего диска; до этого не объявлять всю матрицу проверенной |
| Контекст | Цитаты, оригинал/копия, явные метки, ограничения в UI | Не обещать «без потерь» и не считать совпадение слов разрешением; приёмка по рубрике |

## Сценарий выбранной пользователем очистки

1. Указать точный ненужный объект; сохранить необходимые символы/данные отдельно.
2. Обновить инвентаризацию. Проверить сохранённые, исключённые и выбранные объекты.
3. Выполнить действие в приложении после просмотра подтверждения.
4. Проверить итог: успешные/неудачные/не начатые отдельно; исчезновение только успешного объекта; изменение списка и датированного снимка.
5. Для карантина восстановить под исходным или новым именем и сверить содержимое. Не обещать прирост свободного места после простого переноса в карантин.

## Рубрика истории

Пользовательские цели; последние явные изменения решений; запреты; незавершённые шаги; результаты тестов отдельно от планов и статуса хода; проверяемые ссылки на источник; отсутствие новых фактов; сохранность оригинала. Содержание и внутренние ссылки не публиковать.
