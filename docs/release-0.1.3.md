# OxyMac Cleaner 0.1.3 Preview

- Мастер доступа к диску при первом запуске и после обновления.
- Проверка реального доступа из процесса приложения без чтения личных файлов: отказ, доступность проверенных папок или неопределённый результат.
- Повторная проверка после возвращения из настроек macOS, время последней проверки и точный путь установленной копии.
- Переход в «Полный доступ к диску», показ приложения в Finder и инструкция по восстановлению устаревшей записи.
- Можно продолжить сканирование доступных файлов с учётом ограничений macOS.

Разрешение включает сам пользователь. Автоматического сброса или выдачи прав нет. Пока сборка подписана ad-hoc, сохранение разрешения после обновления не гарантируется; Developer ID ещё не получен.

25 автоматических тестов прошли локально. Apple Silicon, macOS 14+.
