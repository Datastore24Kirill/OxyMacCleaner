# OxyMac Cleaner 0.1.12 Preview

Добавлена справка по действиям во всех разделах приложения на русском и английском: всплывающие подсказки при наведении, пояснения для VoiceOver и кнопка «Как пользоваться» с инструкцией для текущего экрана. В разделе Xcode инструкция меняется вместе с вкладкой архивов, DerivedData или симуляторов.

В архивах «Проверить UUID» теперь называется «Проверить символы отладки», а «Создать копию…» — «Резервная копия…». Отдельное раскрываемое пояснение объясняет dSYM, идентификаторы сборок, ограничения проверки и порядок очистки: копия → карантин → окончательное удаление. Копия сохраняет весь .xcarchive, занимает место и не удаляет оригинал.

Подсказки объясняют лимит архивов и защиту «Не удалять», выбор симуляторов и потерю тестовых данных при удалении, условия очистки DerivedData, фильтры и размеры, восстановление из карантина, импорт и локальную подготовку контекста, установку Ollama, исключения и разрешения macOS.

Логика очистки не изменена. 70 локальных тестов проходят. macOS 14+, Apple Silicon. Preview подписан ad-hoc: сохранение разрешений macOS после обновления пока не гарантируется.
