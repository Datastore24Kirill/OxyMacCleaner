# OxyMac Cleaner 0.1.5 Preview

После успешной проверки доступа мастер показывает только подтверждение и кнопку «Готово» / «Начать сканирование». Кнопки настроек, Finder и повторной проверки, а также инструкции восстановления скрыты. При запуске и перед сканированием подтверждённый доступ больше не вызывает лишний мастер.

При отказе или неопределённом результате инструкции остаются доступны. Проверка после возвращения из настроек сохранена. 28 тестов прошли локально.

Ограничение Preview: ad-hoc подпись может требовать повторного предоставления доступа после обновления. Эта версия исправляет интерфейс, но не заменяет постоянную подпись Developer ID.
