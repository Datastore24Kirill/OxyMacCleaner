# Данные проектов — 0.4.7 Preview

В «Xcode и проекты → Данные проектов» выберите корень проекта и обновите список.
Обход ограничен известными каталогами непосредственно в выбранном проекте. Отдельный ограниченный поиск проектов распознаёт известные маркеры, пропуская каталоги зависимостей; нестандартные пути сборки не распознаются.

| Данные | Возможности |
|---|---|
| SwiftPM `.build`, CocoaPods `Pods`, Node `node_modules`, Python `.venv` | Размер, расположение, описание восстановления; только просмотр |
| Composer `vendor`, Bundler `vendor/bundle`, Gradle `.gradle`, Maven `target`, Python `.venv` по requirements.txt | Только просмотр; маркер проекта и описание восстановления |
| Next.js `.next/cache/webpack` | Проверка и подтверждаемая очистка |
| Rust `target/debug/incremental`, `target/release/incremental` | Проверка и подтверждаемая очистка |

Зависимости могут содержать локальные изменения. Наличие lock-файла не гарантирует их восстановление. Произвольные `build` и `dist` не считаются мусором. Кэш серверных данных Next.js и готовые продукты Rust не входят в очистку.

## Условия очистки

- Выбран корень Git-проекта вне защищённых системных каталогов.
- Распознаны метаданные проекта; Next.js указан в package.json, для Rust есть Cargo.toml и target/.rustc_info.json.
- Каталог игнорируется Git и не содержит отслеживаемых файлов.
- Нет признаков активной сборки; lsof не показывает открытых файлов в проекте и не возвращает предупреждений.
- Данные не менялись последние 10 минут.
- Нет исключений, секретов, исходников, баз, архивов приложений, dSYM, символических ссылок, hard links и облачных placeholders.
- Перед подтверждением сохраняется полный манифест; после подтверждения повторно проверяются содержимое и метаданные проекта.

Удаляется только выбранный кэш, без Корзины и карантина. Следующая сборка может быть медленнее. Команды восстановления не исполняются. Во время очистки нельзя запускать сборку или сервер: проверки процессов не являются блокировкой файловой системы. При ошибке удаления сообщается о возможном частичном результате.

## Основания для границ очистки

- [Next.js build caching](https://nextjs.org/docs/pages/guides/ci-build-caching)
- [Next.js self-hosting and runtime cache](https://nextjs.org/docs/app/guides/self-hosting)
- [Cargo build cache](https://doc.rust-lang.org/cargo/reference/build-cache.html)
- [SwiftPM editable dependencies](https://docs.swift.org/latest/documentation/packagemanagerdocs/editingdependencypackage/)

Проверка: 107 core-тестов, включая сохранение соседних данных и отказ при изменениях после подготовки. Тесты очистки используют только временные синтетические проекты.

Вложенные известные каталоги не учитываются повторно, если уже показан их родитель. Данные без известного правила не предлагаются к удалению.
