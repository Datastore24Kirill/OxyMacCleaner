# Сверка ТЗ — 0.4.5 Preview, 8 октября 2026

Это состояние проверок, а не заявление о завершении всей первой версии. Исходные требования: [SPEC-RU.md](SPEC-RU.md), текущие возможности: [STATUS.md](STATUS.md).

| Критерий ТЗ | Доказательства / состояние | Что остаётся |
|---|---|---|
| Сканирование, отмена, устаревшие данные | Автотесты защит, снимков, исключений, ссылок; 100k/1M наборы; остановка и восстановление журнала после SIGKILL | Реальные аппаратные сбои питания; продолженный снимок не заменяет свежий обход |
| Дубликаты и объём | Хеш и побайтовое сравнение, проверка оставшейся копии, учёт уникальных inode | Нельзя точно вычислить освобождение разделяемых APFS блоков |
| Xcode и проекты | Лимиты архивов, закрепление, необязательная копия, активность сборок; проектные кэши | Дополнительные версии Xcode, гонки с внешними сборками |
| Симуляторы | Обычные/тестовые устройства, выбор по фильтру, свежая проверка состояния; тесты с подменой ответов simctl | Расширенная проверка на разных runtime; тесты не удаляют пользовательские устройства |
| Карантин | Конфликты, отмена, хеши, переполненный APFS-образ; отключение образа при переносе и сканировании, отказ восстановления без диска, гонка отключения с восстановлением (в проверенном прогоне восстановление завершилось раньше отключения); повторное подключение | Аппаратные диски/ФС и внезапная потеря питания; старые записи без UUID имеют прежние ограничения |
| Напоминания | Проверки интервала пять дней, пустого списка и повторов | Зависимость от разрешения macOS на уведомления |
| Контекст | Четыре коротких синтетических сценария, многочастный сценарий 7B, оригинал и резервная копия сохраняются | Независимая оценка реальных историй, смысловые противоречия между частями; без гарантии отсутствия потерь |
| Агенты | 11 вариантов выбора, 9 адаптеров файлов/экспорта; границы показаны в интерфейсе | Поддержка определяется структурой, а не всеми версиями продукта; базы и запуск нового чата не реализованы |
| Локальность | Только loopback Ollama и локальная GGUF, проверки перенаправлений/облачных моделей | Полный независимый сетевой аудит |
| Движок | Установка/повторное использование, прогресс моделей, отмена, проверки ресурсов | Больше сочетаний macOS/памяти и отказов установки |
| Обновление | Загрузка, проверка целостности, запуск с подтверждением и откат | Developer ID отложен; непрерывность разрешений не гарантирована |
| Интерфейс | RU/EN, темы и клавиатура проверялись; VoiceOver пользователь отметил завершённым 8 октября | Более широкий аудит локализации ошибок; проверка пользователя не заменяет аудит доступности всех элементов |

## Следующий этап после этой поставки

1. Проверка Preview пользователем на своих обычных операциях без массовой очистки непроверенных данных.
2. Разбор найденных ошибок с воспроизводимыми примерами, а не расширение списка кнопок.
3. Отдельная оценка контекста на добровольно выбранных историях с ручной рубрикой и без публикации содержимого.
4. Подпись Developer ID — только после возобновления этой задачи пользователем.

Инструкция: [первый запуск](FIRST-LAUNCH-RU.md).
