# Смысловой контекст — 0.4.16 Preview

## Алгоритм

1. Проверенная SHA-256 копия создаётся до обработки. Обработка идёт только через локальную Ollama/GGUF. Оригинал не изменяется.
2. Нативная оболочка сообщений нормализуется с сохранением роли. Явные структурные tool_use выносятся в ручную сверку со ссылкой на исходную запись: запрос команды не доказывает выполнение. Неизвестные записи и tool_result не исключаются этим правилом.
3. Текст делится на части до 9 KB и фрагменты до 1200 символов. Модель формулирует пересказ и выбирает фрагмент; исходную цитату подставляет приложение.
4. Числа, URL и кодовые фрагменты проверяются по приложенной цитате. Неверный язык или неподтверждённые литералы отправляют источник в ручную сверку.
5. Проверяющий проход обязан явно оценить каждое утверждение один раз. Он не может дописывать задачи или советы; возможные пропуски выбираются только как идентификаторы исходных фрагментов. Некорректная схема повторяется один раз, затем операция завершается ошибкой с сохранением прежнего результата и копии.
6. Все распознанные реплики пользователя сохраняются дословно по порядку, включая поздние исправления. Контрольные сообщения агента с признаками тестов, исправлений, ошибок и незавершённой работы также сохраняются исходными словами. Это защита от потери при отказе модели, а не независимое доказательство выполнения. Пересказ, повторяющий тот же защищённый фрагмент, убирается.
7. Готовый текст и фрагменты для ручной сверки разделены. Замечания не попадают в буфер обмена автоматически. Цитирование многострочного источника не позволяет его заголовкам или вложенным ссылкам выдавать себя за структуру отчёта.

## Интерфейс

«Готово к переносу» — редактируемый черновик со ссылками, исходным/новым размером. «Нужно проверить» — отдельные раскрываемые источники и ссылки на полную историю. Есть этап, номер части, таймер, отмена, повтор и прежний режим цитат. После ручной правки проверка помечается устаревшей.

## Ограничения

Смысловой режим остаётся Preview. Отдельный проход той же 7B-модели не гарантирует семантическую точность. Роли определяются по явному формату, не по упоминанию «user» внутри текста. Хронология не означает автоматического выбора действующего решения между разными проектами или ветками. Критические фрагменты агента определяются по признакам слов, поэтому полнота не гарантируется. Тексты команд остаются в исходнике; программа их не выполняет. Фильтр секретов не гарантирует обнаружение всех значений.

Лимит смыслового режима — 30 MB; большие JSONL доступны в режиме цитат. Размер считается в UTF-8 байтах, не токенах; на диске история не уменьшается. Отдельный Mac/новую учётную запись пользователь исключил из приёмки. Developer ID отложен.
