# Приёмка 0.4.18 — возможности очистки

## Объём изменений

Сортировки: рекомендованный порядок, размер по убыванию, дата изменения от старых к новым, тип файла. При равенстве размера порядок стабилен по пути. Сортировка сохраняет выбор и не меняет допустимость очистки. Поиск и смена правила очищают выбор; обновление данных также очищает его, независимо от количества кандидатов.

Карточки личных файлов явно отличаются от восстановимых кэшей разработки. Причина и последствия раскрываются в одной подсказке. Перенос в карантин не объявляется освобождением места.

## Автоматические проверки

- Набор 1505 уникальных кандидатов: ни одна сортировка не теряет и не дублирует файлы; полный обход страниц по 100; правильный итог 1 133 265 байт.
- Поиск последнего файла без зависимости от раскрытой страницы, регистр и пробелы запроса.
- Отдельные типы медиа и установщиков, стабильный порядок равных размеров.
- Реальный временный файл: рекомендация → проверяемый перенос → удаление из снимка → восстановление → побайтовое равенство → повторная рекомендация после свежего чтения.
- Защищённые пути, личная область, возраст, hard links и исключения покрыты прежними тестами.

Семь профильных тестов прошли. Это не замена проверки UI. Все файловые действия в тестах ограничены созданными фикстурами.

## Проверка установленного интерфейса

На этом Mac установлен build 52. На собственном наборе 1505 реальных небольших файлов подтверждено:
- Начальный экран показывает 100 / 1505; выбор по фильтру даёт 1505 и 1,1 MB.
- Пересчёт того же списка сбрасывает выбор до нуля и отключает карантин.
- Поиск fixture-0000.dmg находит файл вне первой сотни.
- Подтверждение переноса содержит один путь и 1 byte; после выполнения кандидатов 1504, выбор пустой.
- Восстановление через карантин возвращает файл; содержимое проверено отдельно (один нулевой байт).
- «Показать ещё 100» даёт 200 / 1504; сортировка по типу сохраняет выбор всех 1504 и возвращает раскрытие к первым 100.
- В тёмной теме визуально проверены карточки, счётчик, фильтры и сортировка. Полная новая матрица тем/размеров окна не проводилась.

Исходный снимок 237450 файлов восстановлен побайтово после теста. Созданные тестовые файлы и только их восстановленная запись карантина убраны. Пользовательские файлы не удалялись. Доступ к защищённым папкам подтверждён после штатного повторного выбора установленной копии в macOS и перезапуска. Это не решает ограничения ad-hoc подписи.

Полный локальный набор: **215 тестов, 0 ошибок**. Сборка и упаковка прошли. Восстановленный файл появляется в рекомендациях после свежего чтения/сканирования; корректировка старого снимка после восстановления не притворяется новым обходом.
