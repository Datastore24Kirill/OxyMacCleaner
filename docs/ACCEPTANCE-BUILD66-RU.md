## Изменения

- Проверка доступа выполняется в фоне по одной операции одновременно; повторные запросы объединяются в один последующий запуск.
- После «Готово» окно доступа не открывается повторно из-за стартовой проверки.
- Сканирование ожидает проверку доступа; перед продолжением проверяется актуальность выбранных корней.
- Помощник обновления запускает приложение через Launch Services (`open -n -W`) и проверяет сигнал готовности. Раннее завершение приводит к откату. Если процесс остаётся жив после тайм-аута, сохраняется возможность ручного восстановления; процесс принудительно не завершается.
