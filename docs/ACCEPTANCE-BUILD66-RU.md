# OxyMac Cleaner — приёмка build 66

15 октября 2026. **Исходники исправлены и проверены; Release66 собран, подпись проверена, установлена локально.** Работает установленная66; публичная версия остаётся1.1.0 (57). [Текущий статус](STATUS.md).

## Изменения

- Проверка доступа выполняется в фоне по одной операции одновременно; повторные запросы объединяются в один последующий запуск.
- После «Готово» окно доступа не открывается повторно из-за стартовой проверки.
- Сканирование ожидает проверку доступа; перед продолжением проверяется актуальность выбранных корней.
- Помощник обновления запускает приложение через Launch Services (`open -n -W`) и проверяет сигнал готовности. Раннее завершение приводит к откату. Если процесс остаётся жив после тайм-аута, сохраняется возможность ручного восстановления; процесс принудительно не завершается.

Это препятствие установки позднее преодолено: пользователь закрыл65, установка66 описана ниже. Публичный релиз не менялся.

## Живая проверка после установки

Пользователь закрыл65. Исправленный production helper установил66 через Launch Services: update.log подтвердил запуск, healthy создан. Info66 и strict codesign установленного bundle проверены.

Системный переключатель Cleaner первоначально был off, затем наблюдался on. Внутри66 открыта панель доступа: «Проверенные защищённые папки доступны. Можно приступать к сканированию». Это подтверждает текущий доступ, но не его сохранение при следующем обновлении ad-hoc сборки.

Обзор и панель доступа отвечали за0,1–2,2с. При переходе в «Агенты и контекст» оборвался native pipe. Отчёт `~/Library/Logs/DiagnosticReports/SkyComputerUseService-2026-10-15-155829.ips` фиксирует падение службы Codex: EXC_BREAKPOINT/SIGTRAP, faulting thread20, Array.remove(at:) → assertionFailure. Cleaner PID94838 продолжал работать. Снимок экрана также отклонён закрытым pipe. Причина всех прежних тайм-аутов этим не устанавливается. На тот момент агенты/симуляторы и остальные диалоги оставались непроверенными; удаления не выполнялись. Последующая частичная проверка агентов описана ниже.
