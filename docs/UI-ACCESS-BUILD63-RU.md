## Наблюдения до восстановления

- Первый запрос CUA к Cleaner вернул интерфейс за 4,6 с; проверка в приложении сообщала отказ, хотя в системных настройках переключатель выглядел включённым.
- Повторный `getApp` системных настроек занял 72 с и вернул неполное accessibility-дерево. Другие операции завершались тайм-аутами вплоть до 100 с.
- В предшествующей попытке запрос по точному пути Cleaner снова завершился `-10005` примерно за 23 с. Инвентаризация приложений работала; обращение по bundle ID оказалось неоднозначным из-за копий rollback/dist. Для выбора приложения используется канонический путь.

## Профиль процесса

Файл диагностики: `/tmp/oxy63-timeout-sample.txt`, время **10:26:53**, PID **71107**.

В профиле **1757/1757** отсчётов основного потока пришлись на ожидание событий `mach_msg2_trap`; остальные потоки простаивали. Footprint — около **4 ГБ**, пик — около **6,8 ГБ**.

Этот профиль **не доказывает зависание Cleaner**: основной поток в момент выборки ожидал события. Accessibility системных настроек также работал медленно. Профиль одного интервала не устанавливает причину всех тайм-аутов и не является полным измерением отзывчивости приложения.

## Восстановление доступа

Через «+» повторно добавлена точная установленная копия `/Users/oxyfire/Applications/OxyMac Cleaner.app`. После добавления переключатель оказался выключенным, поэтому потребовалось явно его включить. После поднятия системного диалога и системного Restart переключатель стал включённым.

В интерфейсе **build 63** подтверждено:

> Проверенные защищённые папки доступны. Можно приступать к сканированию.

Успех относится к фактическим пробам внутри установленного приложения. Он не выводится только из положения системной галочки; различие способов перезапуска само по себе не объявляется причиной прежнего отказа.

## Files: Stop/Retry и незавершённая подготовка

В установленной build 63 Stop показал «Подготовка остановлена» с предложением «Повторить». Retry запустил подготовку заново. На реальном снимке через **116 с** отображалось **4%**; более поздний скриншот также показывал 4%. Завершение списка, выбор и пагинация не подтверждены.

## Профиль повторной подготовки

`/tmp/oxy63-files-retry-sample.txt`, PID **83847**: в стеке рабочего потока отмечены 1374 отсчёта фильтра, 919 — карантинной проверки, 730 — разбора компонентов через Character split. Основной поток около 47% отсчётов ожидал события, остальные приходились на SwiftUI/accessibility. Это профиль конкретного интервала, а не установление причины всех UI-тайм-аутов.

Первоначальный вариант быстрого ASCII-пути с Unicode fallback прошёл 13 целевых тестов, но QA затем обнаружил существовавший обход защиты: POSIX-разделитель `/` рядом с комбинируемым символом мог неверно обрабатываться через Character split, в том числе для защищённого Library. Этот промежуточный вариант заменён.

Финальные исходники `Quarantine.swift` разделяют **все пути по UTF-8**, без возврата к старому Unicode-разбору; ожидания регрессионных тестов требуют защиты Library. QA: **35 целевых тестов PASS, 4,72 с**, журнал `/tmp/oxy-build64-security-tests.log`.

Release-упаковка **build 64 завершена**, `codesign --verify --deep --strict` — PASS; установка не выполнена. Ранее промежуточная упаковка не устанавливалась; работающая версия остаётся **63** с подтверждёнными пробами доступа. Результаты её UI не являются проверкой исправленного кода64.

## Ограничения автоматизации и следующий шаг

После профилирования accessibility-запрос около 19 с возвращал пустое дерево при видимом скриншоте с 4%. Нажатие Stop завершилось `noWindowsAvailable`; reset и повторный `getApp` также дали пустое окно. Последняя проверка процесса показала, что он жив. Нельзя утверждать, что этой попыткой Stop выполнен или что известна причина всех тайм-аутов.

Следующий шаг — восстановить и подтвердить пробы доступа64, затем проверить исправление на реальном списке: подготовку, Stop/Retry, выбор и пагинацию. Целевые тесты не заменяют эту проверку; итоговая UI-приёмка остаётся открытой.

Удаление пользовательских файлов не выполнялось. Этот документ не подтверждает публикацию релиза.
