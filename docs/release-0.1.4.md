# OxyMac Cleaner 0.1.4 Preview

- 15 категорий: фото и изображения, видео, аудио, документы, программы, известные данные игр, данные приложений, кэши, архивы и установщики, исходный код, сборки и зависимости, кэш Xcode, архивы Xcode, системные и другие файлы.
- Содержимое приложений, игровых библиотек и служебных папок относится к владельцу, а не смешивается с личными медиа по расширению.
- Панель показывает пять крупнейших категорий с размерами и объединяет меньшие в «Остальное». «Все категории» раскрывает полный состав с долями и переходом к файлам после сканирования.
- Фильтр категории в списке файлов. Классификация по пути и расширению, без чтения содержимого. Она не означает, что файлы можно безопасно удалить; неизвестные игры могут оставаться в программах или других категориях.
- Включает мастер доступа из 0.1.3: проверка после обновления, точная установленная копия и инструкция восстановления разрешения.

28 автоматических тестов прошли локально. Готовая сборка для Apple Silicon, macOS 14+. Developer ID пока отсутствует; macOS может потребовать повторно разрешить доступ после обновления.
