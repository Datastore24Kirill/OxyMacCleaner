# 0.4.3 Preview — продолжение после сбоя

- Аварийный журнал теперь сохраняет отметки завершённых папок после записи относящихся к ним файлов. После перезапуска доступна команда «Продолжить обход»; незавершённые папки обходятся заново.
- Незавершённая последняя запись игнорируется. Ошибка записи журнала прекращает дальнейшие попытки дописывания, чтобы не превратить оборванную запись в повреждение середины файла.
- Пропуски и ошибки обхода сохраняются вместе с отметками. Старые журналы читаются как частичный результат без возможности продолжения.
- Диск и исключения должны совпадать. Сохранённые наблюдения не становятся актуальными автоматически; для свежих данных нужен новый скан. Это продолжение с завершённых папок, а не с точного файла в незавершённой папке.

159 тестов. Проверен SIGKILL отдельного тестового процесса: восстановлены 60 файлов из трёх завершённых папок, затем получены все 200 файлов без дублей. Отдельно проверена оборванная запись отметки папки. Пользовательские файлы и процессы не затрагивались. Проверка выключения питания не проводилась.
