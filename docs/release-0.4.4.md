# OxyMac Cleaner 0.4.4 Preview

- Восстановление новых записей карантина на прежний путь проверяет UUID исходного тома. При отключённом или заменённом томе предлагается подключить его либо выбрать другое место. Старые записи без UUID совместимы, но не получают эту проверку задним числом.
- Для каждого агента показаны формат, лимит импорта и ограничения. Сжатие не удаляет исходную историю и не освобождает её место.
- Фильтр скрывает присваивания `token` и `refresh_token`; явные следующие шаги и незавершённые действия сохраняются в цитатах даже при пропуске моделью.
- Добавлены инструкция первого запуска и сверка ТЗ с разделением проверенного поведения и оставшихся ограничений.

Проверки: Swift-тесты; локальные синтетические истории qwen2.5:7b; собственный APFS-образ с отключением при переносе, восстановлении и сканировании. Тесты не очищают пользовательские данные. Отключение может проиграть гонку уже завершённому восстановлению: в таком случае проверяется целостность опубликованной копии и состояние журнала. Это не испытание реального отказа оборудования.

VoiceOver пользователь отметил проверенным. Developer ID отложен; Preview не гарантирует сохранение разрешений macOS при обновлениях. Смысловую полноту пересказа по-прежнему проверяет пользователь.
