# OxyMac Cleaner 0.4.8 Preview

Сравнение решений учитывает явные метки автора и проекта: реплики ассистента/инструмента и разные известные проекты не связываются. Неизвестная принадлежность показывается отдельно. Это помощь ручной проверке, а не автоматическое разрешение смысловых противоречий.

Рекомендации получили единый раскрываемый блок «Владелец, последствия и восстановление». Указаны ограничения восстановления архивов, логов и данных симуляторов. Набор разрешённых операций удаления не расширен.

Добавлена проверка конфликта восстановления с последующим восстановлением в другое имя и повторным сканированием. Пользовательские файлы и истории не удалялись. Developer ID отложен, непрерывность разрешений между обновлениями не гарантируется.
