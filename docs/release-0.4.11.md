# OxyMac Cleaner 0.4.11 Preview

Улучшен выбор объектов для очистки: галочки и меню файлов, групповые действия с Xcode-архивами, поиск и выбор по фильтру в DerivedData и тестовых симуляторах, массовое восстановление и удаление выбранного из карантина. Показываются количество и размер выбора.

Смена раздела и фильтров файлов очищает скрытый выбор. Архивы и загрузки включают обычные файлы Downloads; фильтр другой категории больше не скрывает этот раздел. В дубликатах можно выбрать лишние копии, сохранив первую по пути; перед переносом оставшаяся копия проверяется повторно.

Меню карты диска теперь видно в каждой строке. Добавлено копирование путей и открытие историй агентов в Finder. Системные данные, закреплённые архивы, активные сборки и неизвестные объекты остаются защищены.

182 теста пройдены. Developer ID пока отсутствует: после обновления может потребоваться повторно подтвердить прежнее разрешение к диску.
