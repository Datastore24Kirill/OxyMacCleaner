# OxyMac Cleaner 0.1.20 Preview

В разделе «Агенты и контекст» появился список JSONL-файлов Codex и Claude Code: поиск по имени/пути, дата изменения, размер, сортировка от новых к старым и открытие выбранной истории.

Поиск читает только метаданные, без текстов чатов. Содержимое проверяется при открытии. Символические ссылки и облачные объекты пропускаются; ошибки и предел 20 000 объектов показываются как неполный результат. Пустые файлы и файлы больше 30 MB видны, но импорт отключён. Ничего не удаляется.

Apple Silicon, macOS 14+. Подпись ad-hoc; сохранение разрешений после обновлений пока не гарантируется.

Проверка: 116 core-тестов прошли.
