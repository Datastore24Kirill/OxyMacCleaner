# OxyMac Cleaner 0.4.6 Preview

Явные отмены решений, запреты и следующие шаги сохраняются в исходных цитатах даже без метки роли пользователя и при пропуске моделью. Это поиск известных формулировок, а не гарантия смысловой полноты.

В сравнении контекста добавлены подсветка фрагментов, не найденных в результате, и отдельный фильтр. Наличие одной ссылки [L…] больше не считается подтверждением наличия текста. Сравнение учитывает скрытие секретов и проверяет показанный фрагмент, не всю длинную запись. Список стал выше, текст переносится и читается без обрезки строки заголовка.

При каждом запуске проверяется доступ к защищённым папкам. Если есть отказ, показываются инструкции восстановления даже для уже проверенной версии. Приложение не выдаёт разрешение себе; Developer ID остаётся отложенным.

Отчёты пакетной очистки файлов, DerivedData и симуляторов отдельно показывают выполненные, пропущенные и не начатые операции. При отмене остальные файлы не выдаются за попытки удаления.

Очистка пользовательских данных без выбора конкретных объектов не выполнялась. Регрессионные проверки используют собственные файлы.
