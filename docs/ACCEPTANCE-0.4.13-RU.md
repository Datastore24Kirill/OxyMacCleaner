# Приёмка 0.4.13 — имя приложения и восстановление после ошибок

## Исправлено на текущем Mac

В «Полном доступе к диску» теперь видны **OxyMac Cleaner**, фирменный значок и включённый переключатель. Это подтверждено визуально 9 октября 2026.

Launch Services содержала 25 записей резервных/сборочных копий. Удалены только регистрации этих копий, затем зарегистрирован канонический пакет. Для обновления отображения штатно закрыты System Settings и перезапущен пользовательский systemsettingsagent. Файлы резервных копий сохранены; TCC не редактировалась. Это последовательность, которая сработала на этом Mac, а не доказательство, что причиной был только один из её шагов.

Приложение теперь обновляет собственные метаданные через LSRegisterURL при запуске. Оно не перезапускает системные службы и не сбрасывает разрешения автоматически. Старые копии уже сохраняют имя OxyMac Cleaner.app; миграция проверяет содержимое только капсул со старым previous.app, не всех резервных версий при каждом запуске.

## Следующий блок ТЗ: ошибки и следующий шаг

- Краткое объяснение ошибки вместо технического текста на весь диалог.
- Исходное сообщение целиком в раскрывающихся подробностях; доступно выделение и копирование локально в буфер.
- Переход в настройки, локальный движок, истории агентов либо журнал операций в зависимости от причины.
- Несколько причин в одном сообщении не сводятся к одному исправлению.
- Кнопки не повторяют очистку, не меняют разрешения, не отправляют диагностику.
- Во время выполняющейся операции переход отключён; закрытие доступно. Escape закрывает окно.

## Проверка

190 тестов прошли. Добавлены RU/EN сценарии причины/навигации, длинной диагностики, сохранения оригинального сообщения и конкретных русских пояснений. Проверены успешный запуск обновления и откат после раннего выхода на собственных фикстурах. Скрипт качества исправлен после переноса установщика в CleanerCore и включён в GitHub CI.

В UI намеренно импортирован собственный двухбайтный невалидный JSONL: показано русское пояснение, техническое сообщение раскрывается. По результату проверки переход уточнён на «Вернуться к историям». Пользовательские истории, архивы и симуляторы не удалялись.

## Ограничения

При смене ad-hoc сборки 0.4.12 → 0.4.13 macOS снова потребовала привязку: правильное имя само по себе не обеспечивает непрерывность разрешения. Текущая копия повторно добавлена штатно и перезапущена; проверка защищённых папок прошла. Developer ID остаётся отложенным.

До 1.0 остаются критерии из RELEASE-GATES-RU.md: чистый другой Mac/macOS 14, реальные внешние диски, независимая оценка пересказа историй, полный аудит доступности. Эти пункты не закрываются повторным прохождением локальных тестов.
