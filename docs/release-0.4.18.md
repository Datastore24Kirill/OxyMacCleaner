# 0.4.18 Preview — удобнее разбирать кандидатов

- Сортировка по размеру, дате изменения и типу файла; выбор сохраняется при смене порядка.
- Компактные карточки с явным типом и раскрываемыми причинами и последствиями карантина. Личные файлы не называются восстановимыми кэшами.
- Проверен интерфейс на 1505 кандидатах: выбор всего фильтра, раскрытие следующих 100, поиск за пределами первой страницы и сброс выбора после обновления.
- Пройден цикл подтверждения, карантина и восстановления на собственном файле; содержимое совпало.
- Остаток ТЗ отделён от будущих расширений. 215 локальных тестов прошли.

Developer ID отложен; после обновления macOS может потребоваться повторное включение доступа. Свободный пересказ контекста остаётся экспериментальным. Пользовательские данные при проверке не удалялись.
