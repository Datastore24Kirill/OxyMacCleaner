# OxyMac Cleaner 0.1.24 Preview

Отдельная вкладка «Тестовые симуляторы» в разделе «Xcode и проекты»: список устройств XCTestDevices, состояние, подсчёт размеров с остановкой между устройствами и выборочное удаление после подтверждения.

Удаление использует simctl --set для отдельного тестового набора, без удаления папки целиком и без затрагивания обычного набора. Повторно проверяется выключенное состояние устройств и отсутствие активных инструментов разработки. Размеры APFS не гарантируют эквивалентную экономию места.

Пользовательские устройства при проверке не удалялись. Apple Silicon, macOS 14+. Ad-hoc подпись: сохранение разрешений между обновлениями пока не гарантируется.

124 теста прошли, включая проверку отдельного набора и блокировку активных устройств.
