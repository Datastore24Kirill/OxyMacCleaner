# 0.3.0 Preview

- Большие диски: экономнее обход и потоковое сохранение результатов. При сбое восстанавливается завершённая часть журнала; актуальный полный результат требует нового обхода.
- Контекст: сравнение исходника с результатом; модель выбирает ссылки, а приложение подставляет проверенные цитаты. Сохранение противоречий и запретов проверено на длинном синтетическом диалоге. Оригиналы не изменяются.
- Истории Gemini CLI, Continue, Cline и Roo Code добавлены к Codex, Claude Code и Cursor. Поддерживаются конкретные файловые форматы, не все версии и базы данных агентов.
- Карантин можно перенести на другой локальный диск с проверкой копии и восстановить обратно. Переносится уже помещённый в карантин объект; первоначальный карантин по-прежнему требует того же тома.
- Настройки показывают завершённые резервные копии обновлений. Старые можно отправить в Корзину; последняя копия для отката защищена.
- Клавиши Cmd+1…5 для разделов, Cmd+, для настроек, более понятные сообщения распространённых ошибок и доступные подписи новых элементов.

Приложение остаётся Preview. Developer ID и нотариализация отложены; разрешения macOS после замены ad-hoc сборки могут потребовать повторной выдачи. Семантическая полнота выжимки не гарантируется: обязательна проверка человеком.
