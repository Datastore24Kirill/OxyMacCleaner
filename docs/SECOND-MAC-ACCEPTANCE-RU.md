# Проверка на другом Mac — 0.4.14

Цель: Apple Silicon, чистый профиль, macOS 14; не подменять эту проверку компиляцией CI.

1. Скачать ZIP и SHA256SUMS из релиза. Проверить SHA-256, распаковать в Applications. Записать macOS, архитектуру, версию Xcode и приложения.
2. Открыть приложение. Проверить имя/значок в системных настройках; выдать доступ штатно, перезапустить и проверить результат. Не отключать Gatekeeper/SIP; фиксировать блокировку неподписанной Developer ID сборки как ограничение распространения.
3. Создать отдельный тестовый каталог с двумя одинаковыми и одним отличающимся файлами, пустой подпапкой. Сканировать только его; проверить числа/размеры. Переместить выбранную копию в карантин и восстановить; сравнить `shasum -a 256`. Не использовать настоящие документы для приёмки.
4. Проверить отмену, повторное сканирование, изменение файла после снимка и конфликт существующего пути при восстановлении. Ни один конфликт не должен перезаписать файл.
5. RU/EN × светлая/тёмная: все 12 разделов, поиск, пустые списки, длинные пути, прокрутка, подсказки. Проверить минимальный размер 1000×700 и большое окно, Tab/Shift-Tab, Escape, VoiceOver: названия, состояния выбора и фокус.
6. Прочитать список архивов и симуляторов. Записать Xcode/runtime; без специального тестового проекта ничего не удалять.
7. Локальный движок: обнаружение установки, получение списка моделей, видимый прогресс/отмена загрузки. Для пересказа использовать синтетическую завершённую историю. Сверить позднее решение, запрет, незавершённые действия, проваленный тест; исходник должен сохраниться.
8. Обновиться на следующую сборку: прогресс, перезапуск, сохранение снимка и настроек. Отдельно записать поведение разрешения; не считать включённую галочку доказательством доступа.

Результат: дата, среда, шаг, ожидаемое/фактическое поведение, воспроизведение, снимок экрана без личных данных. Непройденный/непроверенный шаг не отмечается успешным. Не публиковать личные пути, истории и логи без проверки содержимого.
