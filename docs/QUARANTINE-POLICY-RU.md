# Где нужен карантин

Решение для 0.1.13: карантин — средство восстановления, а не обязательный этап любого удаления. Сам перенос на том же томе не освобождает место.

| Раздел | Решение | Причина / условия |
| --- | --- | --- |
| Архивы Xcode | Прямое удаление всех сверх лимита или карантин на выбор | Перед обоими действиями создаётся/проверяется полная отдельная копия. Перед прямым удалением — отдельное подтверждение количества и логического объёма, повторная проверка лимита, защиты, копии, исходника и активности сборок. Прямое удаление обходит Корзину. Восстановление вручную из копии. |
| Симуляторы и runtimes | Уже удаляются напрямую штатным simctl | Произвольный перенос каталогов CoreSimulator может нарушить состояние Xcode. Данные устройства теряются. Работающие устройства защищены, удаление подтверждается отдельно. |
| DerivedData | Пока карантин; следующий кандидат на опциональное прямое удаление | Промежуточные сборки, индекс и логи можно пересоздать, но логи могут понадобиться для диагностики. Для отдельного режима удаления нужны выбор типов, повторная проверка allowlist/процессов/неизменности и явное подтверждение. В 0.1.13 этот режим не добавлен. |
| Файлы, крупные папки, архивы и загрузки | Карантин по умолчанию | Расширение, размер и возраст не доказывают ненужность. Пользовательские документы и единственные копии нельзя считать пересоздаваемым кэшем. |
| Точные дубликаты | Карантин по умолчанию | Равенство содержимого не доказывает взаимозаменяемость путей: конкретная копия может использоваться проектом. Сохраняется как минимум одна копия группы. |
| Возможности очистки | Только предложения для просмотра | Старые установщики и крупные давно не изменявшиеся файлы не удаляются автоматически. Дата изменения не равна последнему использованию. |
| Агенты и контекст | Исходная история и проверенная копия сохраняются | Пересказ может потерять решения и детали. Сейчас результат экспортируется отдельно; внутренние базы агентов не чистятся. |
| Локальный движок | Очистки установленных моделей пока нет | Модели теоретически можно загрузить заново, но удаление должно учитывать текущие задачи Ollama и доступность повторной загрузки. |
| Карантин | Отдельное окончательное удаление уже есть | Подтверждение необратимости, для архивов повторная проверка копии. Автоматического удаления нет. |
| Обзор, карта, история, настройки | Собственных новых режимов удаления нет | Карта использует действующее правило карантина обычных папок; остальные экраны показывают данные или настройки. |

## Ограничения прямого удаления архивов

- «Сверх лимита» — текущая политика хранения по Bundle ID и команде, а не доказательство ненужности. Сохранённые пользователем архивы пропускаются.
- Архив должен иметь полную метаинформацию, соответствующие UUID/архитектуры символов и не изменяться 24 часа. Проверка UUID не доказывает полноту DWARF.
- Копия сверяется по составу и SHA-256. Если копия находится на том же диске, перенос данных в неё сам по себе не экономит место. Предпочтителен другой диск.
- Прямое удаление не создаёт записи восстановления в карантине. В истории фиксируются исходный путь и путь копии.
- Отмена действует между архивами; начавшееся рекурсивное удаление не прерывается. При ошибке возможно частичное удаление; сообщение указывает сохранённую копию, список архивов перечитывается.
- Проверки активности/состояния не являются блокировкой внешних процессов. Не запускайте Xcode/сборки и не изменяйте исходники или резервные копии во время операции.
- Логический объём не равен гарантированно освобождаемому месту из-за APFS-клонов и снимков.
