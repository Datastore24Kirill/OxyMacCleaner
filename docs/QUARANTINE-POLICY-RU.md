# Очистка без лишних шагов — 0.1.14

Карантин не обязателен для всех категорий: он нужен, когда пользователь хочет сохранить восстановление. Сам перенос не освобождает место. Список разделов проверен целиком.

| Раздел | Основной путь | Дополнительные возможности / что сохранено |
| --- | --- | --- |
| Обзор | Выбрать диск → сканировать | Выбор отдельной папки и доступ macOS остаются доступными. Сканирование не изменяет файлы. |
| Возможности очистки | Просмотреть предложение → показать файл | Возраст не доказывает ненужность. Предложения не запускают удаление автоматически. |
| Карта диска | Открывать папки, видеть объём | Перенос обычной папки в карантин остаётся в контекстном меню. |
| Файлы и папки | Фильтры → выбрать → карантин | Для пользовательских файлов оставлено восстановление. Нет обязательных дополнительных копий. |
| Архивы и загрузки | Отфильтрованный список файлов | Это пользовательские ZIP/DMG и другие файлы, а не архивы сборок Xcode. Сохраняем карантин. |
| Дубликаты | Найти точные копии → выбрать → карантин | Хотя бы одна копия остаётся. Совпадение содержимого не делает пути взаимозаменяемыми для проектов. |
| Архивы Xcode | Список загружается при входе → удалить сверх лимита → одно подтверждение | Копия — необязательный флажок, выключен по умолчанию. Карантин в «Ещё», диагностика символов и отдельное копирование — в меню архива. Нет обязательной проверки UUID и ожидания 24 часов. |
| DerivedData | Список загружается при входе → выбрать → очистить → одно подтверждение | Прямое удаление только промежуточных сборок, индексов и логов. Карантин в «Ещё». Исходники, SourcePackages и готовые продукты исключены. |
| Симуляторы | Список загружается при входе → выбрать → удалить | Уже использовали штатный simctl без карантина. Сохраняем подтверждение потери данных устройств и защиту запущенных симуляторов. |
| Агенты и контекст | Импортировать экспорт → подготовить → проверить результат | Кнопка «Размер» переименована в «Посмотреть файлы», поскольку открывает сканирование папки. Истории не перезаписываем: потерянный при пересказе смысл нельзя гарантированно восстановить. |
| Локальный движок | Установить / запустить → скачать модель → выбрать | «Проверить» переименовано в «Обновить модели». Установка и загрузка не запускаются автоматически: требуют сети, диска и памяти. |
| Карантин | Вернуть или удалить | Напоминания, папка и восстановление журнала перенесены в «Ещё». Архивы без отдельной копии корректно распознаются и могут быть окончательно удалены после подтверждения. |
| История | Читать результаты | Не добавляем подтверждений или дополнительных действий. |
| Настройки | Тема, язык, исключения, доступ | Не дублируем параметры очистки. Доступ macOS не запрашивается для каждого действия; системные ограничения не обходятся. |

## Минимальные сохраняемые проверки

- Архивы: последние N и «Не удалять» сохраняются, состав перед действием проверяется заново. Недостоверная метаинформация не участвует в массовой очистке.
- Недавно изменённые архивы и DerivedData защищены десятиминутным интервалом; активные процессы Xcode/сборок блокируют операции. Эти проверки не являются блокировкой внешних процессов — не запускайте сборки во время очистки.
- Архивы и dSYM выпущенных версий могут потребоваться для диагностики. Приложение не определяет достоверно, опубликована ли сборка: нужные архивы защищает пользователь.
- Если флажок копии включён, копия сверяется по составу и SHA-256; неуспешное копирование блокирует удаление этого архива. Если флажок выключен, ни выбора папки, ни требования копии нет.
- Прямое удаление обходит Корзину и карантин. Без копии восстановление из приложения невозможно. Рекурсивное удаление может завершиться частично при ошибке; отмена действует между объектами.
- Карантин хранит исходные данные и собственную информацию восстановления. Поэтому отдельная копия перед ним избыточна. Старые записи с привязанной копией сохраняют её проверку.
- Размер логический: из-за APFS-клонов и снимков реальная экономия может отличаться.

## Референс

Официальный сценарий MacPaw — просмотр выбранных Xcode-файлов и Clean Up; обязательные копии/карантин в инструкции не указаны. В документации CleanMyMac X архивы исключены из автоматического выбора. Мы используем этот принцип простого явного выбора, не заявляя полного совпадения внутренних механизмов.
