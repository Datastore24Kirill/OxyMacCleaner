# OxyMac Cleaner 0.1.25 Preview

Тестовые симуляторы добавлены отдельной карточкой в «Возможности очистки». Вкладка загружает список при первом открытии и сохраняет список и измеренные размеры при переходах между разделами.

Удалённая папка XCTestDevices теперь означает пустой список, а не ошибку. Неверный тип объекта, символическая ссылка и отказ доступа остаются ошибками. Никакие устройства автоматически не выбираются и не удаляются.

Apple Silicon, macOS 14+. Ad-hoc подпись: сохранение разрешений между обновлениями не гарантируется.

Удаление симуляторов заранее сообщает о блокирующих процессах. Итог показывает фактически удалённое количество и ошибки; неудачные элементы остаются выделенными для повторной попытки.
