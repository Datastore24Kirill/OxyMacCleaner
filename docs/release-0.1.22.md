# OxyMac Cleaner 0.1.22 Preview

Исправлена обратная связь при очистке архивов Xcode. Если Xcode или сборка активны, операция останавливается до подготовки удаления и явно объясняет причину. Итог показывает число действительно удалённых/перенесённых архивов и ошибок. При нулевом результате с ошибкой появляется уведомление; отчёт доступен непосредственно в разделе «Xcode и проекты».

Защита активных сборок сохранена. Это исправление сообщения о результате, не принудительное удаление защищённых архивов.

121 core-тест прошёл. Apple Silicon, macOS 14+. Ad-hoc подпись: стабильность разрешений macOS между обновлениями пока не гарантируется.
