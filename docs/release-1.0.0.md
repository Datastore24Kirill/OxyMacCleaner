# OxyMac Cleaner 1.0

Первая стабильная версия основных сценариев: анализ диска, просмотр крупных файлов и точных копий, карантин с восстановлением, инструменты Xcode/симуляторов и отдельная локальная подготовка контекста агентов.

## Что завершено к 1.0

- Сканирование отдельно показывает заявленный размер и выделенные файлам блоки. Разреженные виртуальные диски больше не выглядят как объём занятого SSD; старые снимки пересчитываются по сохранённым метаданным.

- Общий план рекомендаций: причины, владелец, риск, условия и восстановление; защищённые объекты недоступны для выбора.
- Совместный предпросмотр исключает известные пересечения путей/inode и сохраняемую копию дубликатов. Размеры неизвестных объектов и неопределённость агрегатов обозначены отдельно.
- Расчёт каталога и предпросмотра выполняется в фоне. Устранён квадратичный поиск пересекающихся путей: на локальном наборе 5 000 объектов предпросмотр ускорился с 4,17 до 0,16 секунды.
- 230 автоматических тестов; размеченные наборы из 44 примеров личных файлов, архивов, кэшей и симуляторов. Проверки обновления/отката и отключения собственного APFS-образа.
- Обновлены инструкция установки, границы поддержки и чек-лист выпуска.

## Установка и ограничения

macOS 14+, Apple Silicon. Скачайте ZIP, распакуйте и перенесите приложение в «Программы». SHA-256 указан в приложенном файле. Установленная версия умеет обновляться через настройки.

Developer ID и нотариализация отложены: сборка подписана ad-hoc. macOS может потребовать повторно подтвердить полный доступ к диску после замены приложения. Не отключайте системную защиту.

Свободный смысловой пересказ контекста остаётся Preview и требует ручной сверки; оригинальные истории не переписываются. Размеры APFS не являются гарантией освобождения места. Приложение ничего не удаляет автоматически.


### Данные Docker

Отдельная категория учитывает выделенное файлам место. Docker.raw и Docker.qcow2, в том числе на внешнем диске, а также данные контейнера Docker защищены от обычной очистки и пропускаются при поиске дубликатов без чтения содержимого. Просмотр категории доступен без включения всех защищённых файлов. Очистка выполняется пользователем через Docker Desktop; приложение даёт ссылку на официальную инструкцию и не запускает prune.

Проверка Docker: 230 тестов, 0 ошибок; подтверждены защита перенесённых дисков, пропуск чтения в поиске дубликатов и учёт выделенного места.

На очень больших снимках (миллионы файлов) начальная загрузка и подготовка индексов могут занимать несколько минут. Убраны лишние обращения к диску при классификации сохранённых путей и подробная проверка заведомо неподходящих кандидатов.
