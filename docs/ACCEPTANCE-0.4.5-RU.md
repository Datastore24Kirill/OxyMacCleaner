# Приёмка 0.4.5 Preview

Пять согласованных направлений. Испытания удаления используют только собственные временные файлы; ответы simctl в тестах подменены. Пользовательские архивы, проекты и устройства не удалялись.

| Направление | Что сделано | Проверка и границы |
|---|---|---|
| 1. Результат очистки | Подтверждённые удаления/переносы файлов, папок, архивов, DerivedData, проектных кэшей и устройств отражаются в списке и сохранённом снимке. Пересчитываются категории, карта и размеры; дубликаты и рекомендации обновляются. | Тест удаления метаданных с похожими префиксами путей, сохранения/загрузки, повторного применения; реальное помещение тестового файла в карантин и восстановление. Существующие тесты архивов/кэшей проверяют ограничения и повторный инвентарь; симуляторы — подмена команд. Снимок остаётся датированным и неполным, не выдаётся за новый обход. Изменения вне приложения требуют повторного сканирования. |
| 2. Контекст | Категории требований, изменений решений, запретов, незавершённых задач и результатов тестов с переходом к исходной строке. | Проверены классификация и байтовые ссылки. Это поиск явных формулировок, не автоматическое определение актуальности. Первые 200 совпадений и ограничение длинных записей указаны в окне. |
| 3. Ошибки/пустые состояния | Исправлен ложный успех чтения DerivedData; объяснено отсутствие моделей при запущенной Ollama; добавлены RU/EN подсказки для контрольной суммы, соединения и отсутствующей модели. На проверке обновления показана активность вместо зависших 100%. | Тесты сообщений сохраняют исходную техническую причину. Широкая проверка всех ошибок ОС на всех локалях остаётся открыта. |
| 4. Обновление/откат | Производственный скрипт установщика вынесен в тестируемое ядро. Ранний выход новой сборки без подтверждения запуска сразу начинает откат; подтверждение перепроверяется перед откатом. | Скрипт реально перемещает тестовые app-каталоги и проверяет маркер запуска; успешный запуск сохраняет копию, аварийный возвращает прежнюю. Только открытие GUI заменено заглушкой. Проверка подписи/ZIP отдельно покрыта существующими тестами. |
| 5. Готовность | Обновлены статус и эта приёмка. | Релиз остаётся Preview: нет Developer ID, нет гарантии сохранения разрешений; нет гарантии смысловой полноты контекста; аппаратные сбои и все версии Xcode/агентов не покрыты. |

## Что остаётся перед стабильной версией

- Пользовательская приёмка реальных выбранных операций и разбор воспроизводимых ошибок.
- Проверка разных runtime и аппаратных носителей без подмены команд.
- Более широкая оценка контекста на добровольно выбранных реальных историях.
- Developer ID и сохранение разрешений — отложенная задача, не обход системной защиты.
