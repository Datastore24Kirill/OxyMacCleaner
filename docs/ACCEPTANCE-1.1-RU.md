# OxyMac Cleaner 1.1 — расширение интеллектуального обзора

Дата: 12 октября 2026. Версия 1.1.0, build 57.

## Реализованные пять пунктов

1. **Большие снимки и списки.** Индекс файлов хранит исходный массив без копии строк и общей сортировки. Ограниченная очередь выбирает только нужную страницу, фильтрация показывает проценты и отменяется. Изменение фильтров отменяет предыдущий запрос. Карта строит дочерние объекты только открытой папки в фоне. Загрузка снимка и журнала имеет прогресс и отмену; отмена не записывает и не удаляет снимок. Устаревший расчёт рекомендаций прекращается.
2. **Владельцы.** Известные корни 11 агентов, Docker, пакеты приложений, контейнеры и Application Support, признаки проектных зависимостей. В интерфейсе указано «по расположению». Для неизвестного пути — «Владелец не определён». Наличие владельца не разрешает очистку; соответствие установленному приложению и манифесту проекта не утверждается.
3. **Новые правила.** Узкие `.pytest_cache`, `.mypy_cache`, `.ruff_cache` внутри выбранного Git-проекта с `pyproject.toml` и точной подписью `CACHEDIR.TAG`. Сохраняются проверки Git ignore/tracked, активности, давности 10 минут, исключений, символических ссылок, защищённых типов, манифеста и хешей маркеров. Перед удалением всё проверяется заново. SQLite-варианты кэша и неизвестные форматы блокируются существующей защитой баз. Удаление не выполняется автоматически. Зависимости/окружения остаются только для просмотра.
4. **Данные агентов.** Сводка по последнему снимку: истории/экспорты, служебные кэши, рабочие данные/базы, неопределённое. Отнесение по пути и расширению, без чтения содержимого. Неполный снимок не доказывает отсутствие данных. Оптимизация выбранной истории создаёт отдельный результат; раздел сводки ничего не удаляет.
5. **Локальные объяснения.** В карточке рекомендации доступны все исходные факты. Установленная модель Ollama может выделить важные идентификаторы фактов. Неизвестные/повторные идентификаторы и дополнительные поля отклоняются. Произвольный текст модели не отображается; ограничения не скрываются. Нет модельного API удаления, изменения риска или автоматического выбора. Без модели и при ошибке остаются исходные факты, запрос можно отменить.

## Ограничения

Чтение большого JSON-снимка остаётся линейным; старые снимки требуют восстановления распределения выделенных блоков. Отмена legacy binary plist возможна после декодирования, а потокового формата — между блоками. Владение и категория агента являются описанием, не доказательством безопасности. Свободный семантический совет модели намеренно заменён выбором исходных фактов. Developer ID по-прежнему отложен.

## Основания правил

- [pytest: cache](https://pytest.org/en/latest/how-to/cache.html) — состояние между запусками и `--cache-clear`.
- [mypy: command line](https://mypy.readthedocs.io/en/stable/command_line.html) — incremental cache.
- [Ruff: configuration / clean](https://docs.astral.sh/ruff/configuration/) — команда очистки кэшей.

Эти документы объясняют назначение кэшей; точные ограничения нашего адаптера перечислены выше и проверяются локально.
