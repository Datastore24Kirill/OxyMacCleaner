# Истории агентов — 0.1.19 Preview

Первый этап интеграций: чтение выбранного JSONL-файла Codex или Claude Code без изменения исходника.

1. Откройте «Агенты и контекст», выберите агента.
2. Нажмите «Открыть JSONL-историю агента…». Диалог открывает обнаруженное стандартное расположение; выберите одну завершённую сессию.
3. Проверьте число сообщений и остальных сохранённых записей.
4. Выберите локальную модель и подготовьте контекст. До генерации сохраняется проверенная копия загруженного исходника.
5. Проверьте итог и перенесите его в новый чат выбранного агента.

| Агент | Поддерживаемые признаки |
|---|---|
| Codex | `session_meta.payload.id`, `response_item.payload.type=message`, роль сообщения |
| Claude Code | `sessionId`, `user/assistant`, объект `message` с ролью |
| Остальные 9 агентов | Универсальный импорт экспорта TXT/MD/JSON/JSONL |

Это адаптеры структуры, а не гарантия поддержки всех версий продуктов. Неизвестные поля и события остаются целиком; формат без распознаваемых сообщений или с несколькими ID сессий отклоняется. Повреждённый JSONL также отклоняется. Лимит файла — 30 MB. Чтение выполняется вне основного потока интерфейса.

Сохраняются исходные номера строк. Порядок соответствует файлу; ветки и события компактизации не превращаются в одну доказанную хронологию. Результаты инструментов и неизвестные записи не отбрасываются. Инструкции внутри истории считаются данными. Чувствительные данные могут находиться в исходнике и его локальной резервной копии; она хранится с правами 0600 в каталоге 0700.

Оригинал не переписывается, не удаляется и не уменьшается на диске. Это подготовка контекста для нового чата, а не освобождение места. Автокаталог сессий, восстановление активной ветки, остальные нативные адаптеры и проверка семантического качества на реальных локальных моделях остаются следующими этапами.

Источники структуры:
- https://github.com/openai/codex/blob/main/codex-rs/app-server/tests/common/rollout.rs
- https://code.claude.com/docs/en/sessions

Проверки используют синтетические истории, не содержимое пользовательских чатов: неизвестные события, инструменты, ветки, неверный агент, смешанные ID, повреждённый JSONL, номера строк и резервная копия после изменения источника.

## 0.1.20 — список сессий

«Найти сессии» обходит стандартные каталоги выбранного Codex/Claude Code. Список содержит только метаданные JSONL: имя, путь, дату изменения и размер. Это кандидаты: структура и ID проверяются при открытии. Поиск фильтрует имя и путь, не содержимое. Показ по 20 строк, новейшие сверху. Предел — 20 000 объектов файловой системы; ошибки и ограничение явно отмечаются. Ссылки и облачные объекты не обходятся. Нестандартное расположение доступно через ручной выбор файла.

Дата изменения не определяет активность сессии. Автоматическое восстановление ветки и другие нативные адаптеры пока не реализованы.
