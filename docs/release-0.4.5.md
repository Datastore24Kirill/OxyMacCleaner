# OxyMac Cleaner 0.4.5 Preview

После очистки обновляются не только списки архивов и кэшей, но и сохранённые результаты анализа: удалённые пути, размеры, категории, карта и рекомендации. Снимок остаётся неполным и датированным; для свежего состояния диска нужен новый обход.

Проверка контекста получила фильтры требований, изменений решений, запретов, незавершённых задач и результатов тестов с переходом к исходной строке. Подсказки не разрешают смысловые противоречия автоматически.

Исправлено сообщение об успешной проверке DerivedData после ошибки. Добавлены подсказки об отсутствии модели/соединения и нарушении целостности; проверка обновления показывает активность вместо неподвижных 100%.

Установщик теперь быстрее возвращает предыдущую версию, если новая завершилась без подтверждения запуска. Скрипт установки и отката проверяется на отдельных тестовых app-каталогах.

Пользовательские данные в испытаниях не очищались. Developer ID отложен; Preview может требовать восстановления разрешения macOS после обновления. Полноту контекста проверяет пользователь.
