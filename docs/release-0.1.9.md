# OxyMac Cleaner 0.1.9 Preview

Добавлен анализ архивов Xcode в разделе «Xcode и проекты»:

- Приложение, Bundle ID, команда, версия и сборка, дата, размер, количество пакетов dSYM.
- Правило «оставлять последние N» отдельно для каждого приложения и команды.
- Закрепление важных архивов сверх лимита; закрепления и лимит сохраняются между запусками.
- Поиск и фильтр архивов сверх лимита, открытие в Finder.
- Неполные/неподдерживаемые метаданные и ошибки чтения исключаются из рекомендаций.
- Чтение в фоне с количеством проверенных архивов и остановкой.

Это анализ, а не удаление: архивы выпущенных версий могут понадобиться для диагностики сбоев. Наличие пакета dSYM не означает проверенное соответствие UUID.

50 локальных тестов прошли. Готовая сборка: macOS 14+, Apple Silicon. Preview подписан ad-hoc; после обновления macOS может потребовать заново подтвердить полный доступ к диску. Developer ID пока отложен.
