## Рабочие деревья Git

Добавлена вкладка «Рабочие деревья» и карточка в сводке. Выберите репозиторий, чтобы увидеть дополнительные checkout, ветки, размеры и причины защиты.

Основной checkout, locked/prunable, изменения, untracked/ignored-файлы, подмодули, специальные флаги индекса, локальные коммиты без remote-tracking refs, недавние изменения и открытые файлы блокируют удаление. Неизвестные состояния также блокируются.

Кандидат удаляется по одному через git worktree remove без force, после подтверждения, повторной проверки регистрации, Git-состояния и манифеста. Ветка остаётся. Карантина нет. Перед удалением завершите задачи агентов: отсутствие открытого файла не доказывает, что задача закончена. Сервер Git не опрашивается.

Apple Silicon, macOS 14+. Требуется доступный Git. Preview остаётся без Developer ID; сохранение разрешений macOS между обновлениями не гарантируется.

Проверено 100 тестами, включая удаление только искусственных рабочих деревьев с сохранением веток. Интерфейс и отмена подтверждения проверены на отдельном тестовом репозитории. Ваши рабочие деревья при разработке не удалялись.
