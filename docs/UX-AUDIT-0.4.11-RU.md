# Аудит удобства 0.4.11

## Принципы

Сверены официальные сценарии CleanMyMac: [просмотр и подтверждение очистки Space Lens](https://macpaw.com/support/cleanmymac/knowledgebase/space-lens-cleanup), [выбор групп загрузок](https://cms-static.macpaw.com/support/cleanmymac/knowledgebase/downloads). Применены явные отметки, итог выбора, действия текущего раздела и подтверждение. Объём файлов не обещает освобождение тех же APFS-блоков. Карантин до удаления занимает место.

## Разделы

| Раздел | Результат проверки и изменения |
|---|---|
| Обзор | Диск, сканирование, остановка и показатели остаются точками входа; массового удаления без просмотра нет |
| Возможности очистки | Карточки показывают объём, владельца, последствия и переход к инструменту; личным файлам добавлены галочки, выбор показанных, объём и групповой карантин |
| Карта диска | Добавлено видимое меню действий каждой строки: просмотр, копирование пути, защита, проверяемый перенос папки/файла; контекстное меню сохранено |
| Файлы и папки | Явные галочки вместо скрытого множественного выделения строк; выбор показанных (до 2000), снятие выбора, количество/объём, меню файла, пустой результат фильтра. Фильтры и смена раздела сбрасывают выбор |
| Архивы и загрузки | Те же элементы выбора; включены обычные файлы Downloads, а не только расширения архивов. Скрытый фильтр категории больше не блокирует раздел |
| Дубликаты | Выбор лишних копий с сохранением первой по пути, снятие выбора, Finder/путь/карантин в меню. Проверка оставшейся копии перед переносом сохранена |
| Xcode: архивы | Галочки, выбор по фильтру на всех страницах, число и объём, удаление/карантин выбранной группы. Лимит массовой рекомендации отделён от явного выбора; закрепления и проверки остаются |
| DerivedData | Поиск проекта/кэша, выбор подходящих по фильтру, снятие выбора, сумма, Finder и копирование пути |
| Симуляторы | Уже есть галочки, выбор по поиску и действия. Смена поиска сбрасывает скрытый выбор устройств; неизвестный размер назван явно |
| Тестовые симуляторы | Поиск, выбор выключенных по фильтру, снятие выбора, число и измеренный объём; неизвестный размер не выдаётся за ноль |
| Рабочие деревья | Размеры, причины блокировки и отдельное проверяемое удаление сохранены; добавлено копирование пути. Массовое удаление не объединяет разные Git-проверки |
| Данные проектов | Размер/восстановление/действие каждого разрешённого кэша уже есть; добавлено копирование пути. Зависимости только для просмотра, без ложных галочек очистки |
| Агенты и контекст | Для файлов истории добавлены Finder/копирование пути; обработка по одной истории, оригиналы не удаляются |
| Локальный движок | Существующие установленные модели, выбор модели и прогресс сохранены; галочки очистки не относятся к этому экрану |
| Карантин | Поиск, галочки, число/размер, восстановление и окончательное удаление выбранных после подтверждения. Конфликты восстановления пропускаются; итог различает выполненные, ошибки и не начатые |
| История операций | Журнал остаётся доступным для чтения/копирования; галочки файлов здесь неуместны |
| Настройки | Тема, язык, исключения, доступ и обновления остаются на своих местах; копии обновлений имеют собственную защиту последней версии |

## Границы проверки

Изменения не разрешают произвольное удаление системных данных, проектов, историй агентов или последней копии дубликата. Файлы сначала перемещаются в проверяемый карантин; Xcode-архивы и разрешённые кэши имеют отдельные операции. Пользовательские данные при приёмке не удаляются. Размеры логические; физическую экономию не гарантируем.

## Выполненная приёмка

182 теста прошли; упаковка Release успешна. На локальной сборке открыты все 12 основных разделов и 6 инструментов Xcode без аварийных диалогов. Проверены галочки файлов, итог 69 файлов / 982,3 MB на текущем снимке, сброс выбора при поиске без совпадений и отключение действия. Проверен выбор четырёх архивов (819,5 MB) и снятие выбора. Файлы не перемещались и не удалялись.

Визуально проверен экран файлов в системной тёмной теме. Настройки повторного сканирования при наличии снимка свёрнуты, чтобы оставить больше места списку. Это не полный визуальный аудит всех состояний/размеров окна и VoiceOver. Снимок сканирования сохранён.
