# Приёмка 0.4.19 — восстановление и снимок

Проблема: успешное восстановление только помечало снимок частичным; файл отсутствовал в списках до нового обхода.

Изменение: после подтверждённого восстановления повторно читаем метаданные отдельных локальных файлов. Добавляем/заменяем запись только внутри исходных корней и вне исключений. Пересчитываем объёмы папок и категорий, сбрасываем результаты поиска дубликатов, сохраняем исходную дату снимка. Для каталогов показываем необходимость повторного обхода; содержимое не выдумываем.

Проверки на собственных фикстурах:
- Повторный путь не создаёт дубль; старый размер заменяется актуальным.
- Внешний путь, исключение, ссылка и каталог не добавляются как файл.
- Реальный карантин → восстановление под новым именем → появление в снимке → сохранение/загрузка снимка.
- Содержимое восстановленного файла совпало с исходным.

Ограничения: точечное обновление не заменяет полный обход, не защищает от последующих внешних изменений и не измеряет гарантированное освобождение блоков APFS.
