# Приёмка 0.4.8 — продолжение пунктов 1–5

1. **Атрибуция контекста.** Явные ведущие метки User/Пользователь/MESSAGE(user) учитываются отдельно от упоминаний роли в тексте. Реплики Assistant/Tool/RECORD исключены из пар решений. Различающиеся явные проекты не связываются. Для текстового экспорта поддерживается метка `[project=…]` сразу после роли; для полного JSON-объекта — поле cwd верхнего уровня. Проект по произвольным путям в тексте не угадывается. Отсутствие меток явно показано. Это не доказательство авторства и не механизм выдачи разрешений; метки недоверенного экспорта могут быть ложными. Произвольные форматы, усечённые JSON и наследование проектной области между записями не распознаются автоматически.
2. **Рекомендации.** У всех семи сводных карточек и личных файлов одинаковый раскрываемый блок: владелец, последствия, восстановление. Причина и ограничения остаются над ним. Для личных файлов владелец-приложение честно неизвестен; восстановление удалённых логов и данных симулятора не обещается. Метаданные не обходят проверки допустимости удаления.
3. **Приёмка очистки.** Собственный тест переносит файл в карантин, создаёт конфликт на исходном пути, подтверждает отказ без замены данных, затем восстанавливает в другое имя и проверяет свежий снимок обоих файлов. Пользовательские объекты без конкретного выбора не удаляются.
4. **Надёжность.** Регрессия конфликтного восстановления дополнена к существующим тестам отключённого носителя, отмены, повреждения журнала, недостатка места и привязок runtime. Реальная потеря питания и другие физические носители не моделируются утверждением о полной готовности.
5. **Интерфейс.** Новые блоки и предупреждения локализованы RU/EN, доступны стандартными DisclosureGroup, с пояснениями. Выполнен поиск жёстко заданных английских Text/Button/TextField: оставшиеся названия брендов, DerivedData и English не заменяются. Это не исчерпывающий аудит всех динамических диагностик и VoiceOver.

Открыто: оценка выбранной реальной истории, приёмка пользовательских объектов, аппаратная матрица, независимый аудит доступности. Developer ID остаётся отложенным. Статус Preview сохраняется.

Проверки: 179 Swift-тестов прошли. Чтение реальной инвентаризации без мутаций: Xcode 27.0 (27A266a), доступен com.apple.CoreSimulator.SimRuntime.iOS-27-0. Это подтверждает инвентаризацию этой установки, не удаление или восстановление runtime.
