# 0.4.2 Preview — продолжение обхода и надёжность

- Все разделы доступны из меню и с клавиатуры. VoiceOver получает признак выбранного раздела и фокус заголовка. Команда остановки — ⌘. Сообщения отмены, занятого назначения, недоступного диска и нехватки места получили понятные пояснения RU/EN.
- «Продолжить обход» появляется у остановленных сканирований этой версии. Полностью пройденные папки сохраняются в снимке; незавершённые обходятся заново. Диск проверяется по идентичности корня, а исключения должны совпадать. Старые наблюдения не становятся свежими: для актуальных итогов нужен новый скан. Аварийный журнал пока восстанавливает только частичный список, без позиции обхода.
- Поддержан JSON-экспорт одной сессии OpenCode (`opencode export`). Идентификаторы сессии, сообщений и частей проверяются, неизвестные части сохраняются. База данных агента не изменяется; лимит JSON — 30 МБ.
- Восстановление карантина можно остановить до перемещения данных. Копирование проверяет доступное место с запасом 10 МБ; ошибки фактического копирования также оставляют исходник. После публикации восстановленного файла операция завершает запись журнала без прерывания.

Проверка: 158 тестов; 100 000 тестовых файлов — полный обход 11,64 с, продолжение после первых 5000 файлов 11,17 с, пиковая память процесса с несколькими снимками около 69 МБ. Импорт истории 100 МБ и проверенная резервная копия — 4,57 с. Локальная 7B сохранила обязательные требования, изменённое решение, результаты тестов и исключила синтетический секрет в многочастном примере. Эти результаты не гарантируют качество на любой истории.

Apple Developer ID по-прежнему отложен. После обновления может понадобиться повторное добавление установленной копии в доступ к диску.
