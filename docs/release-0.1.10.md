# OxyMac Cleaner 0.1.10 Preview

- Проверка UUID и архитектур Mach-O-бинарников архива и файлов dSYM. Работает локально, без запуска бинарников и без установленного Xcode.
- Создание полной резервной копии .xcarchive с проверкой SHA-256 файлов; существующая копия не перезаписывается.
- Перенос одного архива сверх лимита хранения в карантин после выбора отдельной полной копии, повторной проверки и подтверждения.
- Закреплённые архивы, последние N, исключения, изменения за последние 24 часа, неполные метаданные, несовпадения UUID и содержимого блокируют перенос.
- Перед окончательным удалением архива из карантина резервная копия проверяется повторно. Отсутствие/изменение копии блокирует удаление, но не восстановление.
- Карантин на том же диске, восстановление через существующий журнал и проверку целостности. Символические/жёсткие ссылки и облачные объекты не поддерживаются.
- Список архивов разбит на страницы по 10 записей.

Копия занимает дополнительное место. Карантин не освобождает место до отдельного окончательного удаления; копию выпущенной версии следует сохранять для диагностики сбоев. Совпадение UUID не доказывает полноту отладочной информации. Закройте Xcode и сборки перед переносом: автоматическое определение активных сборок пока не реализовано. Отмена во время системного копирования завершается после его возврата.

61 локальных тестов проходят. macOS 14+, Apple Silicon. Сборка ad-hoc; сохранение разрешения на полный доступ к диску между обновлениями пока не гарантируется.
