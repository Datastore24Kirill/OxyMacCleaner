# OxyMac Cleaner 0.1.7 Preview

- Карантин целых обычных папок через контекстное меню списка «Карта диска».
- Предпросмотр количества объектов и объёма, явное подтверждение, повторная проверка состава перед переносом.
- Проверка всего дерева до и после переноса: содержимое файлов, пустые каталоги, метаданные и идентичность. Ссылки и облачные объекты не допускаются.
- Возврат папки на исходное место или в другой путь того же диска без перезаписи конфликтов.
- Журнал prepared/restoring и кнопка «Проверить незавершённые операции» для восстановления состояния после прерывания.
- Изменённый карантин нельзя автоматически восстановить или окончательно удалить: данные остаются для проверки.

Ограничения: только один диск; закрывайте приложения, использующие выбранную папку. Автоматическое определение активности произвольных приложений пока не реализовано. Проекты Git, системные/служебные данные, домашняя папка Library, основные пользовательские корни, пакеты приложений и папки с защищёнными файлами не перемещаются. Специализированная очистка Xcode/симуляторов будет отдельным этапом.

41 автоматический тест прошёл локально. Перенос, возврат, удаление и прерывания проверены только на созданных тестовых данных. Текущий пользовательский обход не прерывался ради обновления. macOS 14+, Apple Silicon, ad-hoc подпись.
