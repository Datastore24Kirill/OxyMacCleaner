## Защита данных при очистке

- Общая очистка больше не может перемещать отдельные файлы пользовательской Library, включая настройки, базы приложений и кэши. Специальные инструменты Xcode остаются доступны.
- Защищены фототеки, медиатеки, dSYM, пакеты Xcode, известные резервные образы, дополнительные типы ключей и исходников. Проверки учитывают регистр.
- Ресурсы рядом с проектом Xcode защищены даже без Git.
- Дополнена защита секретов внутри DerivedData.
- Добавлена документированная политика безопасности с источниками MacPaw/Apple и ограничениями. Архивы выпущенных сборок нужно сохранять для разбора сбоев.

87 тестов успешно пройдены. macOS 14+, Apple Silicon. Preview с ad-hoc подписью: сохранение разрешений macOS при обновлении не гарантируется. Резервная копия архива остаётся добровольной; прямое удаление без неё необратимо.
