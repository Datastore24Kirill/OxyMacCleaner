# 0.4.17 Preview — список возможностей очистки

- Кандидаты показываются порциями по 100, без прежнего предела 1000. Доступно точное число показанных и найденных файлов.
- «Выбрать по фильтру» выбирает все подходящие доступные файлы, включая ещё не показанные. Общий счётчик и объём отражают весь выбор.
- Пересчёт рекомендаций сбрасывает выбор, даже если количество кандидатов осталось прежним. Во время пересчёта выбор и групповое действие недоступны.
- Общая подсказка о последствиях карантина показана один раз; причины предложения остаются у каждого файла.
- Объём списка считается через общий учёт уникальных файлов. Это не обещание фактически освобождаемого места.

Правила безопасности и подтверждение действий сохранены. Файлы пользователя при проверках не удаляются. Developer ID пока отложен; сохранение разрешений между ad-hoc сборками не гарантируется.
