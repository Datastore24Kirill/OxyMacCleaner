# OxyMac Cleaner 0.1.26 Preview

Удаление обычных симуляторов больше не блокируется любой сборкой. Активные xcodebuild связываются с явными UUID из -destination; защищаются конкретные устройства и используемые ими runtimes. Для runtimes также учитываются устройства XCTestDevices.

Если UUID цели не указан, назначение xctest не установлено или открыт Xcode с непрозрачным состоянием GUI-сборок, удаление блокируется с причиной. Запущенные устройства по-прежнему не удаляются. Это проверка текущего состояния, не атомарная блокировка запуска новых тестов: не запускайте работу на выбранных устройствах одновременно с очисткой.

Проверка выполнялась на тестовых данных; пользовательские устройства и чужие сборки не изменялись. Apple Silicon, macOS 14+, ad-hoc подпись.

131 тест прошёл. Read-only проверка на Mac разрешила выключенное устройство iOS 26; к моменту проверки активная xcodebuild-задача уже завершилась. Защита активной цели iOS 27 проверена синтетическим сценарием.
