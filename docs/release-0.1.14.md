# OxyMac Cleaner 0.1.14 Preview

Упрощена очистка архивов: одно подтверждение, резервная копия по необязательному флажку (по умолчанию выключен). Проверка UUID теперь отдельная диагностика, а не условие удаления. Карантин доступен через «Ещё» и больше не требует второй копии. Вместо 24 часов защищены только изменения за последние 10 минут; лимит последних N, «Не удалять», проверки целостности и активности сборок сохранены.

DerivedData можно очистить напрямую после одного подтверждения. Индексы и промежуточные сборки пересоздаются; старые логи теряются. Исходники, SourcePackages и готовые продукты не удаляются. Карантин остаётся в дополнительных действиях.

Списки архивов, кэшей и симуляторов загружаются при первом открытии соответствующего раздела. Ручное обновление доступно. Диагностика и резервное копирование архивов перенесены в меню архива; служебные действия карантина — в «Ещё». Уточнены названия кнопок в разделах агентов и моделей. Подсказки обновлены.

Без копии прямое удаление не имеет восстановления в приложении. Если копия запрошена и проверка не прошла, архив пропускается. Карантин обычных файлов и дубликатов сохранён. Полный аудит разделов: docs/QUARANTINE-POLICY-RU.md.

83 теста проходят. Тесты удаления используют только искусственные данные. macOS 14+, Apple Silicon. Подпись ad-hoc; сохранение разрешений между обновлениями пока не гарантируется.
