# OxyMac Cleaner 0.4.7 Preview

В сравнении истории появились пары связанных решений: более ранняя и поздняя строки рядом, каждая открывает исходник. Связь определяется общими словами, требует ручной проверки и не устанавливает актуальное разрешение. Ограничение: первые 200 подсказок, до 50 пар.

Каталог проектов дополнен Composer, Bundler, Gradle, Maven и Python requirements. Для них доступен только анализ: размер, проект-владелец, маркер и описание восстановления. Пересекающиеся папки не учитываются дважды. Очистка зависимостей не включена.

Добавлены RU/EN пояснения ошибок доступа, изменений данных и активных процессов. Расширены тесты больших историй, проектных каталогов и привязок симуляторов. Пользовательские данные не удалялись. Сохранение разрешений между обновлениями без Developer ID по-прежнему не гарантируется.
