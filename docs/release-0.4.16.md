# OxyMac Cleaner 0.4.16 Preview

- Проверяющая модель больше не дописывает задачи: только явная оценка каждого утверждения и выбор исходных фрагментов.
- Числа, URL и фрагменты кода проверяются по приложенному источнику. Неоценённое утверждение не считается проверенным.
- Реплики пользователя сохранены по порядку; сообщения агента подписаны отдельно. Старые просьбы не объявляются автоматически действующими.
- Структурные tool_use остаются в исходнике и доступны для ручной сверки: вызов инструмента не считается доказательством выполнения. Неизвестные записи и tool_result продолжают обрабатываться.
- Раздельные блоки «Готово к переносу» и «Нужно проверить». Замечания не попадают в копируемый текст автоматически.

Смысловой режим остаётся Preview. Проверяет та же локальная модель; гарантии отсутствия смысловых ошибок нет. Исходник и проверенная резервная копия сохраняются, истории не удаляются. Developer ID отложен.

Проверено: 212 тестов, CI macOS 14/26, реальные истории YooGo и CRM. Готовый текст на этих примерах примерно на 87% меньше исходных файлов, все распознанные пользовательские реплики сохранены. Для надёжности использованы исходные формулировки; качество свободного пересказа 7B не считается доказанным. [Подробная приёмка](https://github.com/Datastore24Kirill/OxyMacCleaner/blob/main/docs/ACCEPTANCE-0.4.16-RU.md).
