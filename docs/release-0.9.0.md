# OxyMac Cleaner 1.0 RC1 — 0.9.0

Первый кандидат версии 1.0 для Apple Silicon, macOS 14+. Техническая версия 0.9.0 совместима с механизмом обновления существующих Preview. Это предварительный, а не стабильный релиз.

В кандидат вошли сканирование и карта диска, точные дубликаты, объяснимые рекомендации, специализированная очистка Xcode/проектов/симуляторов, карантин с восстановлением, локальная подготовка контекста и обновление с откатом.

Закрыта финальная приёмка основных сценариев: 217 тестов, сбои на собственном APFS-образе, реальное обновление 0.4.18 → 0.4.19 с прогрессом и перезапуском, RU/EN и обе темы. В меню доступны компактный и обычный размеры окна. Конечный чек-лист и ограничения: docs/RELEASE-GATES-RU.md; инструкция: docs/FIRST-LAUNCH-RU.md.

Ограничения: Developer ID и нотариализация отложены, разрешение полного доступа может потребовать повторного включения после обновления. Свободный пересказ контекста экспериментальный; оригинал сохраняется. Перенос в карантин не освобождает место на том же диске. Реальный выигрыш APFS заранее не гарантируется. Восстановленные папки требуют нового сканирования.

Распакуйте ZIP и перенесите OxyMac Cleaner.app в «Программы». Xcode/Python для запуска не нужны. Не отключайте защиту macOS.
