# Приёмка 0.4.7: пункты 1–5

1. **Решения в истории.** Добавлено сравнение более раннего и позднего фрагмента с переходом к исходнику. Поиск общих слов работает через границы блоков чтения. Это эвристика, не доказательство противоречия и не определение действующего разрешения. Не учитывает автоматически автора и проект. Первые 200 сигналов, до 50 пар; длинные записи имеют прежний предел. Реальные истории без выбора пользователя не обрабатывались.
2. **Интеллектуальная очистка.** Дополнение SMART-CLEANUP-PLAN-RU.md включено в первую версию. Каталог проектов расширен Composer, Bundler, Gradle, Maven, Python requirements. Новые данные только для просмотра: команды установки не исполняются, удаление отключено. Показывается владелец-проект, маркер и версия правила. Пересекающиеся каталоги не суммируются повторно.
3. **Очистка.** Повторная регрессия на собственных файлах включает реальный перенос в карантин, восстановление и пересчёт снимка, а также удаление узкого кэша проекта с сохранением соседних данных. Пользовательские объекты для удаления не выбраны; их приёмка остаётся открытой.
4. **Совместимость и сбои.** Расширены проверки runtime-идентификаторов iOS 18.5/26 и watchOS 26 на синтетических ответах simctl; активная и неизвестная привязка блокируют удаление. Это не проверка установленных runtime этих версий. Существующие проверки нехватки места, отключённого payload, отмены, повреждённого журнала и восстановления входят в регрессию. Аппаратная матрица и внезапное отключение питания не закрыты.
5. **Интерфейс.** Подсказки новых действий на RU/EN; читаемые причины отказа доступа, изменения данных и активности. Полная аудитория доступности и всех исторических сообщений ошибок остаётся задачей приёмки. Developer ID отложен.

Версия остаётся Preview. Нет обещаний отсутствия смысловых потерь или гарантированного освобождения APFS-блоков.

Локально прошли 175 Swift-тестов. GUI: синтетическая история дала одну пару раннего/позднего решения; переход открыл позднюю строку со смещения 29. При одновременном раскрытии двух блоков обнаружено сжатие панелей; блоки сделаны взаимоисключающими. Разрешение после замены ad-hoc сборки восстановлено для прежнего приложения, защищённые папки доступны после полного перезапуска. Снимок 237450 файлов сохранён.
