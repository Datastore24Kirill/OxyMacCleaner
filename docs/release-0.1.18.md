# OxyMac Cleaner 0.1.18 Preview

Добавлен раздел «Xcode и проекты → Данные проектов» и карточка в возможностях очистки.

- Размеры и подсказки восстановления для SwiftPM, CocoaPods, Node и Python; зависимости доступны только для просмотра.
- Проверяемая очистка webpack-кэша Next.js и incremental-кэша Rust.
- Защита отслеживаемых файлов, секретов, свежих и используемых данных. Повторная проверка после подтверждения.
- 107 тестов прошли. Реальные пользовательские данные при разработке не очищались.

Готовая сборка для Apple Silicon, macOS 14+. Приложение пока подписано ad-hoc: стабильность разрешений macOS между обновлениями не гарантируется. Developer ID отложен. Архив содержит готовое приложение; SHA256SUMS.txt позволяет проверить скачивание.
