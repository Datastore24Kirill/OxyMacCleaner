# 0.3.1 Preview — состояние Ollama и имена резервных копий

- Экран локального движка автоматически проверяет Ollama и установленные модели. Для работающего движка скрыты установка и запуск; скачивание предлагается только отсутствующим моделям. Установленную модель можно выбрать без сетевой загрузки.
- Загрузка сразу показывает состояние, затем процент и объём текущего файла модели; есть отмена. Поток без сообщения об успешном завершении больше не считается успешной установкой. Список моделей перепроверяется перед выбором.
- Резервная версия обновления сохраняет имя `OxyMac Cleaner.app` в каталоге `rollback`. Старые завершённые копии `previous.app` переносятся в эту структуру без удаления содержимого. Это исправляет причину неверного имени, но не гарантирует сохранение разрешений macOS у ad-hoc сборок и не сбрасывает TCC.
- Английский интерфейс получил переводы статусов обновления и шаблона нового контекста; актуализированы подсказки запуска движка.

147 тестов прошли. Проверены успешное обновление и восстановление предыдущей версии после неудачного запуска на изолированных тестовых приложениях. Реальные модели и пользовательские данные не удалялись.
