# Приёмка 0.4.10

- Ручной выбор отдельного архива отделён от лимита массовой очистки. Последний архив разрешён для явного удаления и карантина после подтверждения.
- Общая реализация одиночных и массовых действий сохраняет свежую инвентаризацию, сверку манифеста, необязательную проверенную копию, исключения, защиту закреплённых архивов, свежих записей и активных сборок.
- 182 теста прошли. Новые регрессии: последний архив заблокирован для массового действия, разрешён для ручного; карантин → восстановление → удаление на фикстуре; ручной выбор не снимает защиту других последних архивов, закреплённых и неизвестных объектов.
- Реальные пользовательские архивы не удалялись и не перемещались.

Локально установлена 0.4.10 (44). После восстановления прежнего разрешения проверенные защищённые папки доступны. В UI у последнего архива проверены оба пункта меню: «Удалить…» и «В карантин…». Действия над пользовательскими архивами не запускались.
