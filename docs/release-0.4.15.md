# OxyMac Cleaner 0.4.15 Preview

- Новый смысловой пересказ историй: краткие утверждения, ссылки на исходник и отдельный проверяющий проход локальной модели.
- Цитаты подставляет приложение; модель выбирает только фрагмент. Возможные пропуски и противоречия доступны для ручной сверки.
- Экран «было → стало», процент сокращения текста, этапы, части, таймер, отмена и понятное восстановление после ошибки.
- Прежняя выжимка цитат остаётся отдельным режимом. Оригиналы и проверенные копии сохраняются.

Смысловой режим — до 30 MB; большая история доступна в режиме цитат. Проверяет та же локальная модель, поэтому результат требует вашей сверки и не считается сжатием без потерь. Developer ID по-прежнему отложен.
