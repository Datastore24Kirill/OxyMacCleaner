## Единая сводка возможностей очистки

- В разделе «Возможности очистки» появились карточки дубликатов, архивов Xcode сверх лимита, кэшей DerivedData и симуляторов.
- Карточки показывают число кандидатов, известный объём, дату проверки, причину и ограничения. «Посмотреть» открывает нужную вкладку без выбора файлов для удаления.
- «Обновить сводку» читает данные Xcode и симуляторов с этапами и остановкой. Поиск точных дубликатов запускается отдельно, поскольку требует сравнения содержимого.
- Закреплённые архивы и исключения учитываются; неполный список архивов не даёт рекомендации очистки. Недавно изменённые/неполные кэши и занятые симуляторы не предлагаются.
- Пересекающиеся категории не складываются в обещанную экономию. Личные файлы по-прежнему доступны ниже с фильтрами.

91 тест пройден. Никакие пользовательские файлы при проверках не очищались. macOS 14+, Apple Silicon. Preview с ad-hoc подписью: стабильность разрешений при обновлениях пока не гарантируется.
