# Безопасность очистки — 0.1.15

Проверено 6 октября 2026. Это описание реализованных ограничений, а не гарантия отсутствия любых ошибок. Полный доступ к диску даёт право читать данные, но не делает их мусором. Размер, возраст и одинаковый хеш не доказывают ненужность файла.

## Что берём у CleanMyMac

MacPaw описывает Safety Database: запреты для важных системных расположений, исключения для конкретных приложений и проверку совместимости. Даже среди кэшей бывают лицензии, настройки и офлайн-библиотеки. Поэтому OxyMac не очищает произвольные папки Cache или Library. В документации CleanMyMac X архивы Xcode и некоторые другие категории исключены из Smart Selection. Внутренняя база MacPaw не публична: мы используем опубликованные принципы, не заявляем эквивалентную защиту.

## Матрица действий

| Данные | Действие в текущей версии |
|---|---|
| Системные деревья macOS, Applications, /opt | Общая очистка заблокирована; не меняем SIP, TCC, SDK, приложения, Homebrew и компоненты загрузки |
| Пользовательская Library, включая Preferences, Containers, почту, браузеры и кэши | Общая очистка файлов и папок заблокирована; специальные операции Xcode перечислены отдельно ниже |
| Проекты, Git/Hg/SVN, исходники, Xcode-пакеты, ресурсы рядом с проектом | Общая очистка заблокирована для распознаваемых типов/маркеров; Xcode-проекты защищаются и без Git |
| Ключи, сертификаты, provisioning, keychain, .env и известные хранилища учётных данных | Общая очистка заблокирована; для DerivedData отдельная проверка секретов |
| Фототеки, медиатеки, dSYM, разреженные резервные образы, известные пакеты виртуальных машин | Нельзя убрать ни пакет, ни отдельный вложенный файл общей очисткой |
| Истории и настройки агентов | Известные каталоги защищены; сжатие работает с импортированной копией, исходные базы не переписываются |
| Архивы .xcarchive | Только специальный раздел, лимит + «Не удалять» + проверка метаданных/изменений/активности сборки + подтверждение. Резервная копия и карантин остаются опциями |
| DerivedData | Только Build/Intermediates.noindex, Index.noindex, Logs в стандартной папке; не SourcePackages, продукты сборки, SDK или вся папка проекта. Проверка активности и 10 минут покоя |
| Симуляторы | Только штатный simctl и повторная проверка состояния. Запущенные устройства защищены. Удаление устройства теряет его установленные приложения и тестовые данные; это не безусловно восстанавливаемый кэш |
| Большие файлы, старые загрузки, дубликаты | Кандидаты на просмотр. Личные файлы не удаляются автоматически. Карантин для обычных файлов сохраняется |

Правила учитывают регистр имён пакетов и расширений. Стандартная папка Archives доступна только специальной операции с архивами; запрет на обычное перемещение файлов из Library остаётся в силе.

## Что обязательно сохранять разработчику

Apple рекомендует сохранять архив **каждой распространяемой сборки**: внутри находятся бинарники и соответствующие dSYM для символикации сбоев. Нельзя определить по одному возрасту или лимиту, выпущена ли сборка. «Сверх лимита» не означает «безопасно удалить». Такие релизные архивы нужно отметить «Не удалять» либо сохранить проверенную копию отдельно. Удаление старого архива не удалит Xcode, но может лишить возможности разбирать падения конкретной версии.

Источник: https://developer.apple.com/documentation/xcode/building-your-app-to-include-debugging-information

## Защита в момент операции

- Повторная проверка состава и содержимого каталога перед действием; изменившиеся после просмотра файлы блокируют операцию.
- Символические ссылки, специальные файлы и жёсткие ссылки в каталогах не допускаются; облачные каталоги не перемещаются.
- Пользовательские исключения проверяются перед изменением данных.
- Восстановление не перезаписывает существующий путь; журнал и проверка содержимого сохраняются.
- Нет фонового автоматического удаления, принудительного закрытия Xcode или отключения системной защиты.
- Прямое удаление архива/кэша необратимо без отдельной копии; ошибка файловой системы может оставить частичный результат. Во время очистки не начинайте сборку и не меняйте выбранные файлы: проверки состояния не являются блокировкой других процессов.

## Известные границы и дальнейшее развитие

Каталог правил не охватывает все приложения и все языки. Неизвестные личные файлы могут быть ценными — решение о них остаётся за пользователем. Не реализованы определение опубликованных сборок через App Store Connect и полная база версий/исключений сторонних программ. До появления специальных проверенных правил новые виды кэшей, Docker volumes, резервные копии устройств и модели агентов не добавляются в массовую очистку.

## Проверка

87 тестов успешно пройдены. Новые регрессии проверяют системные/пользовательские пути, варианты регистра, ключи, пакет фототеки целиком и отдельный файл внутри, ресурс рядом с Xcode-проектом без Git. Ранее существующие тесты проверяют архивы, изменения после просмотра, исключения, активные сборки, симуляторы через имитацию команд и восстановление. Деструктивные проверки выполняются только на созданных тестами данных. Пользовательские данные в ходе аудита не очищались.
