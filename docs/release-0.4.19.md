# 0.4.19 Preview — список после восстановления

Восстановленные отдельные файлы теперь сразу возвращаются в списки и рекомендации, если их путь входит в область текущего снимка и не исключён. Метаданные читаются заново; повторные записи не увеличивают объём. Это работает для одиночного и группового восстановления, а также нового имени внутри области снимка.

Восстановленные папки требуют нового сканирования: приложение явно сообщает об этом. Возраст снимка сохраняется, частичный снимок не объявляется полным. Символические ссылки, недоступные и облачные файлы без локальной копии не добавляются автоматически.

Developer ID остаётся отложенным; macOS может потребовать повторное включение доступа после обновления.
