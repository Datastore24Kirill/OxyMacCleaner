# Проверка единого каталога рекомендаций

Версия правил: 1. Сборка: 0.9.1 / 1.0 RC2.

## Что измеряется

Кандидат означает «можно предложить для ручного просмотра», а не «ненужный файл».
Размеченный набор находится в `SmartRecommendationTests.testRuleQualityLabelledFixtures`.
В нём 16 искусственных случаев: 3 ожидаемых кандидата и 13 отрицательных примеров.
Проверяются пороги 90/180 дней и 500 MB, личные папки, исходники, секреты,
пакеты приложений и фотобиблиотек, зависимости, Git, жёсткие ссылки, пустые файлы,
будущая дата и имя файла с текстом инструкции. Последнее остаётся обычным именем.

Команда воспроизведения: `swift test --filter SmartRecommendationTests`.
Тест печатает TP/FP/TN/FN и время проверки. Это синтетический контроль регрессий,
не оценка точности на всех пользовательских дисках и не процент безопасности.

## Проверки защит вне классификационного набора

| Проверка | Ожидание |
|---|---|
| Исключённый файл | Заблокирован, отсутствует в предпросмотре |
| Неполная инвентаризация архивов | Все архивы заблокированы |
| Последний сохраняемый архив | Не предлагается автоматически; ручной выбор доступен в разделе архивов |
| Непроверенный/недавно изменённый DerivedData | Заблокирован |
| Зависимости проекта | Только просмотр |
| Worktree с изменениями | Заблокирован |
| Запущенный симулятор | Заблокирован |
| Выключенный недоступный симулятор | Ручной просмотр, размер неизвестен |
| Личный файл одновременно является сохраняемой копией дубликата | Убирается из совместного предпросмотра |
| Родитель и потомок, повторный путь и inode | Учитываются один раз |
| Неизвестный размер | Отдельный счётчик; не подменяется нулевым размером |
| Агрегированные размеры папок | Явное предупреждение о непроверенных жёстких ссылках между папками |

Проверки удаления и восстановления остаются в прежних специализированных тестах.
Каталог не выполняет команды и не является разрешением удалить файл.

## Ограничения

Предпросмотр использует метаданные разных источников и показывает даты.
Перед действием профильный раздел заново проверяет объект и активность.
Размеры папок не содержат полных списков inode: их сумма предварительная.
Общие блоки APFS, snapshots, карантин и неизвестные размеры не позволяют обещать
немедленно освобождаемое место. Активность процессов не проверяется постоянно при
отрисовке списка. Модель не нужна, данные наружу не отправляются.

Универсальное определение владельца, рекомендации по произвольным базам агентов
и семантические пояснения не входят в этот каталог. Истории агентов остаются в
отдельном сценарии с сохранением оригиналов.
