# 0.4.1 Preview — проверка изменений во всей истории

В окне «Сравнить с исходником» появилась команда «Проверить изменения во всей истории».

- Локальный проход по всем страницам ищет явные формулировки смены решений, запретов и результатов тестов на русском и английском.
- Результаты ведут к исходной строке, включая записи за пределами первой страницы. Ничего не удаляется и не отправляется в сеть.
- Есть прогресс и отмена. В списке показываются первые 200 совпадений; общее число найденных мест указывается отдельно.
- Для ограничения памяти у очень длинных записей проверяются первые 64 КБ. Количество таких записей явно показано. Это поиск признаков, а не семантическое доказательство противоречий и не выбор актуального решения.

Проверены переходы к поздним строкам с Unicode, отмена, ограничение списка и учёт длинных записей. Developer ID по-прежнему отсутствует; после обновления может понадобиться повторное добавление установленного приложения в доступ к диску.
