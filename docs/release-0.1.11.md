# OxyMac Cleaner 0.1.11 Preview

## Архивы

«Закрепить» переименовано в «Не удалять»: архив защищён независимо от лимита. Показываем количество и объём сверх лимита. Общая кнопка создаёт/проверяет полные копии в выбранной папке, затем отдельно предлагает перенос прошедших проверки архивов. Ошибки сохраняются в отчёте, оригиналы пропускаются. Копии на том же диске тоже занимают место — предпочтителен другой диск.

В карантине добавлено отдельное подтверждаемое окончательное удаление всех архивов. Каждая копия снова проверяется перед удалением. Отмена очереди действует между операциями.

## Симуляторы

Устройства и runtimes показаны раздельно. Можно выбрать ненужные вручную, отметить недоступные выключенные устройства или runtimes, не использовавшиеся 90+ дней. Возраст — повод проверить выбор, а не автоматическое разрешение удаления.

Удаление выполняется штатным simctl по конкретному UUID после подтверждения. Состояние проверяется повторно перед каждой командой, затем перечитывается результат. Запущенные/переходные состояния и защищённые runtimes блокируются. Runtime с запущенным связанным устройством не удаляется. Xcode и обнаруженные сборки должны быть закрыты. Ошибки инструментов и незавершённое асинхронное удаление показываются в отчёте.

Удаление устройств безвозвратно стирает их приложения и тестовые данные, без карантина. Удаление runtime может оставить существующие устройства недоступными. Runtime можно загрузить заново через Xcode, если нужная версия доступна.

## DerivedData

Связь с проектом берётся из info.plist Xcode. Доступны только Build/Intermediates.noindex, Index.noindex и Logs распознанных проектов. SourcePackages, исходники, готовые продукты и неизвестные общие кэши не включаются. Перед переносом в карантин проверяются процессы Xcode/сборок, последние изменения (10 минут), исключения и целостность. Проверка процессов консервативна, но не является атомарной блокировкой новых сборок: не запускайте их во время очистки. Следующая сборка/индексирование займут больше времени.

Исправлена нормализация относительных путей manifest для эквивалентных /var и /private/var. 70 локальных тестов проходят. Реальные пользовательские архивы, кэши и симуляторы в ходе разработки не удалялись и не переносились.

macOS 14+, Apple Silicon. Preview по-прежнему подписан ad-hoc: сохранение разрешений после обновления пока не гарантируется.
