# Правила команды OxyMac Cleaner

- Следуйте ролям и рабочему процессу в [docs/TEAM-WORKFLOW-RU.md](docs/TEAM-WORKFLOW-RU.md).
- Для нетривиальной реализации выделяйте отдельного субагента `developer`. Ведущий агент координирует работу, проверяет и интегрирует результат; QA остаётся отдельной ролью. При нехватке слотов задачи выполняются по очереди.
- Перед делегированием задайте цель, критерии готовности и разрешённые файлы. Один файл одновременно изменяет один исполнитель.
- Только один исполнитель управляет GUI и установленным приложением. Не удаляйте пользовательские данные ради тестов и не изменяйте базы разрешений macOS.
- Не смешивайте результаты автотестов, ревью исходников и живой проверки. Текущий статус фиксируйте в docs/STATUS.md, доказательства — в отчёте соответствующей сборки.
